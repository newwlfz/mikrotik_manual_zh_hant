2026 年 8 月 25 日文件變更摘要。

## 管理工具 {#management-tools}

- **[SSH](/docs/management-tools/ssh)**、**[Console](/docs/management-tools/console)**、**[Quick Set](/docs/management-tools/quick-set)**、**[RoMON](/docs/management-tools/romon)**、**[FlashFig](/docs/management-tools/flashfig)**、**[WinBox](/docs/management-tools/winbox)**、**[Serial Console](/docs/management-tools/serial-console)** 和 **[WebFig](/docs/management-tools/webfig)**：全面重寫了措辭與格式，並將其 CLI 引數表移入 CLI Reference。

## 入門 {#getting-started}

- **[RouterOS 授權](/docs/getting-started/routeros-licensing)**：修正了語法，並補全了 CLI Reference 中的授權引數說明（同時重新調整了 [CHR 授權](/docs/getting-started/routeros-licensing/chr/chr-licensing) 頁面的樣式）。
- **[備份](/docs/getting-started/configuration-management/backup)**：修正了語法，並將其 CLI 引數移入 CLI Reference。
- **[升級到 v7](/docs/getting-started/upgrading-to-v7)** 和 **[支援輸出檔案](/docs/getting-started/supout-rif)**：修正了語法，並添加了相關交叉連結。
- **[預設配置](/docs/getting-started/configuration-management/default-configurations)**：改用表格替代專案符號列表重新調整樣式，並改進了措辭。
- **[軟體規格](/docs/getting-started/software-specifications)**：修正了語法，並添加了相關交叉連結。
- **[網路基礎](/docs/getting-started/networking-fundamentals)**：添加了交叉連結，並在 IPv6 鄰居發現部分用 Mermaid 圖替換了 PNG 示意圖。

## 容器 {#containers}

- **[容器應用](/docs/containers/apps)**：大幅重做了 Custom Apps 部分——由 "User-Addable Apps" 更名而來，並將 "How to add apps" 擴充套件為三種方法——此外當天還修復了若干拼寫錯誤和措辭問題。
