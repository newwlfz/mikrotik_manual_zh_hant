## 快速開始 {#quickstart}

- 從 [https://mikrotik.com/download](https://mikrotik.com/download) 下載最新版本的 SwitchOS 軟體；
- 將您的計算機連線到其中一個乙太網埠；
- 將裝置連線到電源；
- 將計算機的 IP 地址設定為 192.168.88.2；
- 開啟 Web 瀏覽器，預設的管理 IP 地址為 192.168.88.1，使用者名稱為 **admin**，無密碼（某些型號的使用者名稱和無線密碼請檢視標籤）；
- 在 Upgrade 標籤頁中透過 Web 瀏覽器上傳檔案，升級完成後裝置將重啟；
- 設定您的密碼以保護裝置安全。

## 擴充套件插槽和埠 {#extension-slots-and-ports}

- 十六個千兆乙太網埠。
- 兩個 - 10G SFP+ 埠。

## 配置 {#configuration}

使用 WinBox 實用程式並點選 Neighbors 列表即可發現該裝置。預設管理地址為 192.168.88.1。SwOS 是一款專為交換器設計的簡單軟體。我們建議從本指南開始，以熟悉其功能：[https://mt.lv/help](https://mt.lv/help) 出於恢復目的，可以引導裝置以進行重新安裝，請參閱相關章節。

## 供電 {#powering}

本裝置可透過兩路 100-240 V AC ⏦ 輸入供電。

本裝置在最大負載下的功耗最高為 10 W。帶外接裝置時最高為 13 W。

## 安裝 {#mounting}

本裝置設計用於室內，可使用隨附的機架安裝件安裝在機架式機箱中，也可放置在桌面上。如果指定用途為機架式機箱，請使用十字螺絲刀將機架耳固定在裝置兩側：

- 將機架耳固定到裝置兩側，並擰緊四顆螺絲將其固定到位，如圖所示。

![](/img/837a6d2bb5f312fe.webp)

- 將裝置放入機架式機箱並對齊孔位，使裝置能夠方便地裝入。
- 擰緊螺絲將其固定到位。本裝置沒有防水保護，請確保將裝置放置在乾燥且通風的環境中。*本裝置的安裝和配置應由具備資質的人員完成。* *我們建議為我們的裝置使用 Cat6 網線。*

## 按鈕和跳線 {#buttons-and-jumpers}

在啟動期間按住此按鈕，直到 LED 燈開始閃爍。鬆開按鈕即可重設 SwOS 配置並載入備份軟體以進行重新安裝和升級。
