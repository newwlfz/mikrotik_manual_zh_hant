## 快速開始 {#quickstart}

- 從 [https://mikrotik.com/download](https://mikrotik.com/download) 下載最新的 SwitchOS 軟體版本；
- 將您的計算機連線到任一乙太網埠；
- 將裝置連線到電源；
- 將計算機的 IP 地址設定為 192.168.88.3；
- 開啟 Web 瀏覽器，預設管理 IP 地址為 192.168.88.1，使用者名稱為 **admin**，無密碼（部分型號請檢視貼紙上的使用者名稱和無線密碼）；
- 透過 Web 瀏覽器將檔案上傳到 Upgrade 標籤頁，升級後設備將重啟；
- 設定您的密碼以保護裝置。

## 供電 {#powering}

裝置可透過電源插孔或交流電源供電。

- 直接輸入電源插孔（外徑 5.5mm、內徑 2mm，母頭，中心正極插頭）接受 48-57V 直流。
- 交流輸入範圍 100-240 V。
- 最大功耗（不含附件）12 W。
- 最大功耗 162 W。

## PoE-Out {#poe-out}

- PoE-Out 支援 802.3 af/at 和被動 PoE
- PoE-Out 埠 ether1-ether8：PoE-Out 電壓：低電壓 28V；
- 高電壓 54V（交流輸入）或 48-57V（直流輸入）
- 低電壓 PoE-Out 最大輸出電流：1000 mA（每埠）。
- 高電壓 PoE-Out 最大輸出電流：625 mA（每埠）。
- 總輸出功率 140 W。PoE-Out 高電壓取決於所用電源：如果使用交流電源，PoE-Out 高電壓始終約為 54V；如果使用 DC Jack 電源，PoE-Out 高電壓將與 DC Jack 的輸入電壓一致。PoE-Out 低電壓恆定約為 28V。**如果交流電源和直流電源同時使用，PoE-Out 高電壓將取決於較高的輸入電壓。僅當 DC Jack 輸入超過 54 伏時才會變化。*

### 連線到 PoE 介面卡 {#connecting-to-a-poe-adapter}

- 將裝置的乙太網線纜連線到 PoE 介面卡的 PoE+DATA 埠。
- 將來自本地網路（LAN）的乙太網線纜連線到 PoE 介面卡。
- 將電源線連線到介面卡，然後將電源線插入電源插座。

## LED {#led}

電源將由裝置判斷並給出相應的電壓，如果需求為低電壓，LED 將亮綠燈；如果需求為高電壓，LED 將亮紅燈；當用戶端裝置無需供電時則不亮。
