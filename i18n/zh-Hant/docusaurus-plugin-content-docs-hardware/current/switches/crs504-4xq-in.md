## 快速開始 {#quickstart}

- 用您的 PC 連線到任意乙太網埠；
- 將裝置連線到電源；
- 將網路卡的 IP 設定配置為 192.168.88.2/24；
- 在網頁瀏覽器中使用 WebFig，或使用 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox)。**提供多種配置方式以確保可訪問性；**
- 在網頁瀏覽器中開啟 [https://192.168.88.1](https://192.168.88.1) 開始設定。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁查詢裝置。繼續使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（對於某些型號，請檢視貼紙上的使用者和無線密碼）；
- 如需手動更新裝置，請訪問 mikrotik.com，選擇您的型號，並在 "Downloads" 部分找到所需的軟體包；
- 將下載的軟體包上傳到 WebFig 或 WinBox 的 "Files" 選單，然後重啟裝置；
- 將 RouterOS 軟體升級到最新版本，可確保獲得最佳效能、穩定性和安全更新；
- 設定您的路由器密碼。

## 安裝 {#mounting}

本裝置設計用於室內使用，可以使用隨附的機架安裝配件安裝在機架機箱中，也可以放置在桌面上。如果希望放置在平面上，請在路由器底部貼上橡膠腳墊；如果指定用於機架機箱，請使用十字螺絲刀將機架掛耳安裝到裝置兩側：

- 將機架掛耳安裝到裝置兩側，並擰緊四顆螺絲將其固定到位，如圖所示。
- 將裝置放入機架機箱並對齊孔位，使裝置能夠方便地安裝。
- 擰緊螺絲將其固定到位。

## 配置 {#configuration}

RouterOS 的完整文件可在以下地址獲取：[https://mt.lv/help](https://mt.lv/help) 您可以使用網頁瀏覽器中的 WebFig 或 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 配置裝置。**提供多種配置方式以確保可訪問性。** **要開始設定，請在網頁瀏覽器中開啟 [https://192.168.88.1](https://192.168.88.1) 開始設定。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁查詢裝置。繼續使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（對於某些型號，請檢視貼紙上的使用者和無線密碼）。該裝置配備一個 RJ45 序列埠，預設設定為 115200 bit/s、8 個數據位、1 個停止位、無奇偶校驗。出於恢復目的，可以從網路重新安裝裝置，請參閱復位按鈕。

## 供電 {#powering}

該裝置可透過兩個交流輸入供電，電壓範圍為 AC ⏦ 100-240 V。雙電源冗餘，採用 IEC 電源介面。DC 插孔輸入電壓 36-57 V DC。2 針端子輸入電壓 36-57 V DC。PoE in 輸入 43-57 V DC。最大負載下的功耗可達 41 W。

## 復位按鈕 {#reset-button}

- 要重設配置，請斷開裝置電源，按住復位按鈕，當 USER (USR) LED 開始閃爍時鬆開。
- 要載入備份載入程式，請在通電前按住復位按鈕，三秒後鬆開。
- 要啟動 Netinstall 過程（以 BOOTP 模式啟動裝置以重新安裝 RouterOS），請按住復位按鈕，給裝置通電，等待 USER (USR) LED 閃爍後變為穩定。當 USR LED 熄滅時，鬆開復位按鈕。無論使用上述哪種方式，如果在裝置通電前按下按鈕，系統將載入備份 RouterBOOT 載入程式。這對於 RouterBOOT 偵錯和恢復很有用。
