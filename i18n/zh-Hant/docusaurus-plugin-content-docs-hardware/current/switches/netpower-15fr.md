### netPower 15FR (CRS318-1Fi-15Fr-2S-OUT) {#netpower-15fr-crs318-1fi-15fr-2s-out}

## 快速開始 {#quickstart}

- 將您的 PC 連線到任意乙太網埠；
- 將裝置連線到電源；
- 將網路卡的 IP 設定配置為 192.168.88.2/24；
- 在 Web 瀏覽器中使用 WebFig，或使用 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox)。**有多種配置方法可用，以確保可訪問性；**
- 在 Web 瀏覽器中開啟 [https://192.168.88.1](https://192.168.88.1) 以開始設定。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁來查詢裝置。繼續使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（或者，對於某些型號，請檢視貼紙上的使用者和無線密碼）；
- 如需手動更新裝置，請訪問 mikrotik.com，選擇您的型號，並在 "Downloads" 部分找到所需的軟體包；
- 將下載的軟體包上傳到 WebFig 或 WinBox 的 "Files" 選單，並重啟裝置；
- 透過將 RouterOS 軟體升級到最新版本，您可以確保獲得最佳效能、穩定性和安全更新；
- 設定路由器密碼。

RouterOS 和 SwOS 的完整文件可在以下地址獲取：[https://mt.lv/help](https://mt.lv/help) 您可以使用 Web 瀏覽器中的 WebFig 或 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 來配置裝置。**有多種配置方法可用，以確保可訪問性。** **要開始設定，請在 Web 瀏覽器中開啟 [https://192.168.88.1](https://192.168.88.1) 以啟動設定。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁來查詢裝置。繼續使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（或者，對於某些型號，請檢視貼紙上的使用者和無線密碼）。裝置配備 RS-232 序列埠，預設設定為 115200 bit/s、8 個數據位、1 個停止位、無奇偶校驗。出於恢復目的，可以從網路重新安裝裝置，請參閱復位按鈕。

Marvell Prestera 交換晶片功能使用者手冊

裝置支援啟動 RouterOS（用於完整的路由和交換功能）或 SwOS（僅用於交換操作）。預設情況下，裝置啟動進入 RouterOS，但您可以按以下方式切換到另一個作業系統：

## 按鈕和跳線 {#buttons-and-jumpers}

RouterBOOT 復位按鈕具有以下功能。按住按鈕並接通電源，然後：

- 當綠色 LED 開始閃爍時鬆開按鈕，以將 RouterOS 配置重設為預設值。
- 當 LED 變為常亮綠色時鬆開按鈕，以清除所有配置和預設值。
- 在 LED 不再亮起（約 20 秒）後鬆開按鈕，以使裝置查詢 Netinstall 伺服器（透過網路重新安裝 RouterOS 時需要）。無論使用上述哪個選項，如果在裝置接通電源之前按下按鈕，系統將載入備用 RouterBOOT 載入器。適用於 RouterBOOT 偵錯和恢復。
