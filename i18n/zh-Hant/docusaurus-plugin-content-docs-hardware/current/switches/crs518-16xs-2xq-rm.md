## 快速開始 {#quickstart}

- 用 PC 連線到任意乙太網埠；
- 將裝置連線到電源；
- 將網路卡的 IP 設定配置為 192.168.88.2/24；
- 使用網頁瀏覽器中的 WebFig 或 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox)。**提供多種配置方式以確保可訪問性；**
- 在網頁瀏覽器中開啟 [https://192.168.88.1](https://192.168.88.1) 開始設定。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁查詢裝置。接著使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（部分型號請檢視貼紙上的使用者和無線密碼）；
- 如需手動更新裝置，請訪問 mikrotik.com，選擇您的型號，並在 "Downloads" 部分找到所需的軟體包；
- 將下載的軟體包上傳到 WebFig 或 WinBox 的 "Files" 選單，然後重啟裝置；
- 將 RouterOS 軟體升級到最新版本，可確保獲得最佳效能、穩定性和安全更新；
- 設定路由器密碼。

## 安裝 {#mounting}

本裝置設計用於室內，可使用隨附的機架安裝件安裝在機架機箱中，也可以放置在桌面上。如果希望將路由器放置在平面上，請在路由器底部安裝橡膠腳墊；如果指定用於機架機箱，請使用十字螺絲刀在裝置兩側安裝機架耳：

- 如圖所示，將機架耳安裝到裝置兩側，並擰緊四顆螺絲將其固定到位。
- 將裝置放入機架機箱，對準孔位，使裝置便於安裝。
- 擰緊螺絲將其固定到位。

## 配置 {#configuration}

RouterOS 的完整文件可在以下地址獲取：[https://mt.lv/help](https://mt.lv/help) 您可以使用網頁瀏覽器中的 WebFig 或 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 配置裝置。**提供多種配置方式以確保可訪問性。** **開始設定，請在網頁瀏覽器中開啟 [https://192.168.88.1](https://192.168.88.1) 進行設定。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁查詢裝置。接著使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（部分型號請檢視貼紙上的使用者和無線密碼）。裝置配有 RJ45 序列埠，預設設定為 115200 bit/s、8 位資料位、1 位停止位、無奇偶校驗。出於恢復目的，可以從網路重新安裝裝置，請參閱復位按鈕。

## 復位按鈕 {#reset-button}

RouterBOOT 復位按鈕具有以下功能。按住按鈕並接通電源，然後：

- 當綠色 LED 開始閃爍時鬆開按鈕，可將 RouterOS 配置復位為預設值。
- 當 LED 變為常亮綠色時鬆開按鈕，可清除所有配置和預設設定。
- 當 LED 熄滅後（約 20 秒）鬆開按鈕，裝置會查詢 Netinstall 伺服器（透過網路重新安裝 RouterOS 時需要）。無論使用上述哪種方式，如果在裝置通電前按住按鈕，系統都會載入備份的 RouterBOOT 載入程式。適用於 RouterBOOT 偵錯和恢復。
