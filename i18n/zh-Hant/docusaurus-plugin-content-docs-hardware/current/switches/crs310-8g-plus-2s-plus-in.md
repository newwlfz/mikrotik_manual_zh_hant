## 快速開始 {#quickstart}

- 將您的 PC 連線到任意乙太網埠；
- 將裝置連線到電源；
- 將網路卡的 IP 設定配置為 192.168.88.2/24；
- 在網頁瀏覽器中使用 WebFig，或使用 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox)。**提供多種配置方法以確保可訪問性；**
- 在網頁瀏覽器中開啟 https://192.168.88.1 開始設定。如果該 IP 地址不可用，請使用 **WinBox** 並選擇 "**Neighbors**" 標籤頁來查詢裝置。然後使用 MAC 地址進行連線。使用者名稱為 "**admin**"，沒有密碼（或者，對於某些型號，請檢視貼紙上的使用者和無線密碼）；
- 如需手動更新裝置，請訪問 mikrotik.com，選擇您的型號，並在 "Downloads" 部分找到所需的軟體包；
- 將下載的軟體包上傳到 WebFig 或 WinBox 的 "Files" 選單，然後重啟裝置；
- 將 RouterOS 軟體升級到最新版本，即可確保獲得最佳效能、穩定性和安全更新；
- 設定您的路由器密碼。

## 安裝 {#mounting}

![](/img/27bf22aa32ecbced.webp)

本裝置設計用於室內使用，可使用隨附的機架安裝件安裝在機架機箱中，也可以放置在桌面上。如果希望放置在平面上，請在路由器底部安裝橡膠腳墊；如果指定用於機架機箱，請使用十字螺絲刀將機架耳片安裝到裝置兩側。

- 如右圖所示，將機架耳片安裝到裝置兩側，並擰緊四顆螺絲將其固定到位。
- 將裝置放入機架機箱，並使其與孔位對齊，以便裝置方便地安裝。
- 擰緊螺絲將其固定到位。本裝置的 IP 防護等級為 IP20。本裝置沒有防水保護，請確保將裝置放置在乾燥通風的環境中。我們建議為我們的裝置使用遮蔽 Cat5/6 網線。*本裝置的安裝和配置應由合格人員完成。*

## 供電 {#powering}

本裝置可透過直接輸入電源插孔（外徑 5.5 mm、內徑 2 mm，母頭，中心針為正極插頭）接受 18-57 V DC ⎓ 供電。本裝置在最大負載下的功耗最高可達 34 W。

## 配置 {#configuration}

RouterOS 的完整文件可在 [https://mt.lv/help](https://mt.lv/help) 獲取。可以透過網頁瀏覽器中的 **WebFig** 或 **WinBox** 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 來配置裝置。**提供多種配置方法以確保可訪問性。**

在網頁瀏覽器中開啟 https://192.168.88.1 開始設定。如果該 IP 地址不可用，請使用 **WinBox** 並選擇 "**Neighbors**" 標籤頁來查詢裝置。然後使用 MAC 地址進行連線。使用者名稱為 "**admin**"，沒有密碼（或者，對於某些型號，請檢視貼紙上的使用者和無線密碼）。出於恢復目的，可以從網路重新安裝裝置，請參閱復位按鈕。

Marvell Prestera 交換晶片的功能在 [Marvell Prestera switch chip features](/docs/bridging-and-switching/marvell-prestera-switch-chip-features) 手冊中有描述。

## 復位按鈕 {#reset-button}

復位按鈕有三個功能：

- 要重設配置，請斷開裝置電源，按住 Reset 按鈕，再次接通電源，並在 PWR LED 開始閃爍時鬆開按鈕。
- 要載入備份載入程式，請在通電前按住 Reset 按鈕，三秒後鬆開。
- 要使用 [Netinstall](/docs/getting-started/installation-and-upgrade/netinstall) 工具重新安裝 RouterOS，請讓裝置進入 BOOTP 模式。有兩種載入程式選項可用：**Regular Booter** 和 **Backup Booter**。建議對兩個選項都進行驗證，以防其中一個無法使用。

- **Regular Booter:** 要進入 etherboot 模式，請在給裝置通電並等待 1–2 秒後按下 **Reset** 按鈕。
- **Backup Booter:** 關閉裝置。按住 **Reset** 按鈕，然後給裝置上電。等待 **LED** 序列（閃爍 → 常亮 → 熄滅），然後鬆開按鈕。裝置將啟動進入 **BOOTP** 模式，可透過 Netinstall 重新安裝 RouterOS。視型號而定，這可能由 **USR, USER, System** 或 **ACT** LED 指示，或由 SFP 埠 LED 指示。

無論使用上述哪個選項，如果在裝置通電之前按下按鈕，系統都會載入備份 RouterBOOT 載入程式。這對於 RouterBOOT 偵錯和恢復很有用。

## LED 指示燈 {#led-indicators}

- 當路由器透過 DC 插孔或 PoE 供電時，電源 LED 點亮。
- 使用者 LED 可在 RouterOS 中配置。
- 埠 LED 指示各個乙太網和 SFP 埠的活動狀態。
