## 快速開始 {#quickstart}

- 將你的 PC 連線到任意乙太網埠；
- 將裝置連線到電源；
- 將網路卡的 IP 設定配置為 192.168.88.2/24；
- 在網頁瀏覽器中使用 WebFig，或使用 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox)。**提供多種配置方式以確保可訪問性；**
- 在網頁瀏覽器中開啟 [https://192.168.88.1](https://192.168.88.1) 開始設定。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁來查詢裝置。然後使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（或者，對於某些型號，請檢視貼紙上的使用者和無線密碼）；
- 如需手動更新裝置，請訪問 mikrotik.com，選擇你的型號，並在 "Downloads" 部分找到所需的軟體包；
- 將下載的軟體包上傳到 WebFig 或 WinBox 的 "Files" 選單，然後重啟裝置；
- 將 RouterOS 軟體升級到最新版本，可確保獲得最佳效能、穩定性和安全更新；
- 設定路由器密碼。

## 安裝 {#mounting}

本裝置設計用於室內使用，可使用隨附的機架安裝支架安裝在機架機箱中，也可以直接放置在桌面上。如果希望放置在平面上，請在路由器底部貼上橡膠腳墊；如果指定用途是機架機箱，請使用十字螺絲刀在裝置兩側安裝機架掛耳：

- 將機架掛耳和後部支撐掛耳安裝到裝置兩側，並擰緊四顆螺絲將其固定到位，如圖所示。

![](/img/837a6d2bb5f312fe.webp)

- 將裝置放入機架機箱並對齊孔位，使裝置能夠順利裝入。
- 擰緊螺絲將其固定到位。本裝置不具備防水汙染保護，請確保將裝置放置在乾燥且通風的環境中。我們建議為我們的裝置使用 Cat6 網線。本裝置的安裝和配置應由具備資質的人員完成。

## 供電 {#powering}

本機配備兩個 250 W 電源，支援 100-240 V ⏦（~ 50/60 Hz，最大 4.5 A）。無附加負載時的最大功耗為 28 W，在最大負載下可達到 215 W。

RouterOS 的完整文件可在以下地址獲取：[https://mt.lv/help](https://mt.lv/help) 你可以使用網頁瀏覽器中的 WebFig 或 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 來配置裝置。**提供多種配置方式以確保可訪問性。** **要開始設定，請在網頁瀏覽器中開啟 [https://192.168.88.1](https://192.168.88.1) 開始設定。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁來查詢裝置。然後使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（或者，對於某些型號，請檢視貼紙上的使用者和無線密碼）。本裝置配備一個 RJ45 序列埠，預設設定為 115200 bit/s、8 個數據位、1 個停止位、無奇偶校驗。出於恢復目的，可以從網路重新安裝裝置，請參閱 Reset 按鈕。

## 按鈕 {#buttons}

**Reset 按鈕**：

- 在啟動期間按住此按鈕，直到 USER LED 燈開始閃爍，鬆開按鈕即可重設 RouterOS 配置。
- 按住 Reset 按鈕並給裝置上電（等待 "USER" LED 閃爍後變為穩定的 "On"，當 "USER" LED 變為 "Off" 時——鬆開 Reset 按鈕）——裝置會以 BOOTP 模式啟動，以便使用 Netinstall 重新安裝 RouterOS。**Netinstall 過程使用 MGMT/BOOT 乙太網埠。** 有關使用 Netinstall 恢復工具的資訊，請參閱 RouterOS 文件。無論使用上述哪種方式，如果在裝置上電之前按鈕已被按下，系統都將載入備份 RouterBOOT 載入程式。請在 LED 開始閃爍之前鬆開按鈕，以便僅載入備份 RouterBOOT 而不進行重設。這對於 RouterBOOT 偵錯和恢復很有用。

## LED 指示燈 {#led-indicators}

- 路由器上電時 PWR LED 點亮。
- USER LED 指示裝置在啟動進入不同模式（例如重設配置或啟動裝置以使用 Netinstall 工具）時的狀態。
- FAULT LED 指示任一散熱風扇出現問題。
- 三角形 LED（上排）指示 PoE 輸出狀態。綠色 LED 表示相應埠使用低電壓，紅色 LED 表示高電壓。單個綠色 LED 閃爍：啟動低電壓裝置時出現問題。單個紅色 LED 閃爍：高電壓裝置出現問題。
- SFP+ 埠綠色 LED 指示各 SFP+ 埠活動狀態。
