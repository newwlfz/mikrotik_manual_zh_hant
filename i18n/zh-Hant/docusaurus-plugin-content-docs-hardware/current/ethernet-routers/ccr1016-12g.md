## 快速開始 {#quickstart}

- 將您的 PC 連線到標有 **MGMT/BOOT** 的埠或第一個乙太網埠；
- 將裝置連線到電源；
- 將網路卡的 IP 設定配置為 192.168.88.2/24；
- 應使用 Web 瀏覽器中的 **WebFig** 或 **WinBox** 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 進行配置。**提供多種配置方法以確保可訪問性；**
- 在 Web 瀏覽器中開啟 192.168.88.1 開始設定。如果該 IP 地址不可用，請使用 **WinBox** 並選擇 "**Neighbors**" 標籤頁來查詢裝置。然後使用 MAC 地址進行連線。使用者名稱為 "**admin**"，沒有密碼（或對於某些型號，請在貼紙上檢視使用者和無線密碼）；
- 如需手動更新裝置，請訪問 mikrotik.com，選擇您的型號，並在 "Downloads" 部分找到所需的軟體包；
- 將下載的軟體包上傳到 **WebFig** 或 **WinBox** 的 "**Files**" 選單，然後重啟裝置；
- 透過將 RouterOS 軟體升級到最新版本，您可以確保最佳的效能、穩定性和安全更新；
- 設定您的路由器密碼。

## 供電 {#powering}

本裝置透過 IEC C14 標準聯結器供電，支援 110/220 V。兩個 PSU 用於冗餘，每個 100 - 240 V ~1.5 A，50/60 Hz。最大功耗 42 W。

## 擴充套件插槽和埠 {#extension-slots-and-ports}

- 十二個 10/100/1000 Mbit/s 千兆乙太網，支援 Auto-MDI/X；
- 整合記憶體 2 GB；
- micro-USB AB 型埠；
- RS232 序列控制檯埠，序列埠預設設定為 115200bit/s、8 個數據位、1 個停止位、無奇偶校驗。Ether12 埠支援 Etherboot/Netinstall 以重新安裝 RouterOS。

## 按鈕和跳線 {#buttons-and-jumpers}

**Reset 按鈕**：

- 在啟動過程中按住此按鈕，直到 USER LED 燈開始閃爍，鬆開按鈕即可重設 RouterOS 配置。
- 按住 Reset 按鈕並給裝置上電（等待 "USER" LED 閃爍後變為穩定 "On"，當 "USER" LED 變為 "Off" 時 - 鬆開 Reset 按鈕）- 裝置將以 BOOTP 模式啟動，使用 [Netinstall](/docs/getting-started/installation-and-upgrade/netinstall) 重新安裝 RouterOS。**MGMT/BOOT 乙太網埠用於 Netinstall 過程。** 有關使用 Netinstall 恢復工具的說明，請參閱 RouterOS 文件。

無論使用上述哪種方式，如果在裝置上電前按下按鈕，系統將載入備份的 RouterBOOT 載入程式。在 LED 開始閃爍之前鬆開按鈕，則僅載入備份 RouterBOOT 而不進行重設。這對於 RouterBOOT 偵錯和恢復很有用。
