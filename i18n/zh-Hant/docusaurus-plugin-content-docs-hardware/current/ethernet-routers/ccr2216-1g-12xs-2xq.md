## [CCR2216-1G-12XS-2XQ](https://mikrotik.com/product/ccr2216_1g_12xs_2xq) {#ccr2216-1g-12xs-2xq}

全新的 MikroTik 旗艦產品，擁有整支艦隊的強大效能。藉助 L3 Hardware Offloading，釋放 100 Gigabit 網路的威力！這款路由器可以方便地直接替換現有的 CCR1072 部署。完整的規格和宣傳冊請參見 [CCR2216-1G-12XS-2XQ 產品頁面](https://mikrotik.com/product/ccr2216_1g_12xs_2xq)。

## 安全警告 {#safety-warnings}

- 在對任何裝置進行操作之前，請了解與電路相關的危險，並熟悉防止事故的標準做法。
- 本產品的最終處置應遵循所有國家法律和法規。
- 裝置的安裝必須符合當地和國家的電氣規範。
- 本裝置設計用於安裝在機架中。開始安裝之前，請仔細閱讀安裝說明。使用不正確的硬體或不遵循正確的操作步驟，可能會給人員帶來危險情況並對系統造成損壞。
- 在將系統連線到電源之前，請閱讀安裝說明。
- 客戶有責任遵守當地國家的法規，包括在合法的頻率通道內執行、輸出功率、佈線要求以及動態頻率選擇（DFS）要求。所有 MikroTik 裝置都必須由專業人員安裝。

## 首次使用 {#first-use}

- 將您的 PC 連線到標有 **MGMT/ETH/BOOT** 的埠或第一個乙太網埠；
- 將裝置連線到電源；
- 將網路卡的 IP 設定配置為 192.168.88.2/24；
- 配置應透過網頁瀏覽器中的 **WebFig** 或 **WinBox** 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 進行。**提供多種配置方式以確保可訪問性；**
- 在網頁瀏覽器中開啟 192.168.88.1 開始設定。如果該 IP 地址不可用，請使用 **WinBox** 並選擇 "**Neighbors**" 標籤頁來查詢裝置。然後使用 MAC 地址進行連線。使用者名稱為 "**admin**"，沒有密碼（或者，對於某些型號，請檢視貼紙上的使用者和無線密碼）；
- 如需手動更新裝置，請訪問 mikrotik.com，選擇您的型號，然後在 "Downloads" 部分找到所需的軟體包；
- 將下載的軟體包上傳到 **WebFig** 或 **WinBox** 的 "**Files**" 選單，然後重啟裝置；
- 透過將 RouterOS 軟體升級到最新版本，您可以確保獲得最佳效能、穩定性和安全更新；
- 設定您的路由器密碼。

## 供電 {#powering}

本裝置可由兩個冗餘電源供電，每個電源均接受 100-240 V AC 電源。您可以單獨使用其中任意一個，也可以同時使用兩個。最大功耗為 128 W。

## 擴充套件插槽和埠 {#extension-slots-and-ports}

- 產品程式碼 CCR2216-1G-12XS-2XQ
- CPU AL73400 2 GHz
- CPU 架構 ARM 64bit
- CPU 核心數 16
- 記憶體大小 16 GB
- 記憶體型別 DDR4
- 儲存 128 MB，NAND
- 1G 乙太網埠數量 1
- 25G SFP28 埠數量 12
- 100G QSFP28 埠數量 2
- M.2 SATA 插槽數量 2
- 作業系統 RouterOS（License level 6）
- 交換晶片型號 98DX8525
- 交換晶片與 CPU 的連線 4x25 Gbps
- 尺寸 443 x 367 x 44 mm
- 工作溫度 -20°C 至 +60°C
- 100G QSFP28 支援的速率：1x 100G；2x 50G；1x 50G；1x 40G；4x 25G；4x 10G；4x 1G。不支援：2x 40G
- 25G SFP28 支援的速率：1x 25G；1x 10G；1x 2.5G；1x 1G。不支援：1x 5G

CCR2216-1G-12XS-2XQ 的兩個 M.2 插槽採用 SATA3 連線。推薦使用 SATA3 M.2 2280mm B+M key SSD 磁碟，容量不受限制。

## 安裝 {#mounting}

本裝置設計用於室內使用，可以使用隨附的機架安裝件安裝在機架機箱中，也可以放置在桌面上。使用十字螺絲刀在裝置兩側以及裝置背面兩側（如果預定用途是安裝在機架機箱中）安裝機架安裝耳：

- 將支架安裝到右前側。
- 安裝右後支架。
- 將支架安裝到左前側。
- 安裝左後支架。
- 將長支架安裝到機架上，並用螺孔安裝裝置，使裝置安裝得順手合適。
- 如有需要，安裝線纜管理支架。

## 配置 {#configuration}

RouterOS 的完整文件可在以下地址獲取：[https://mt.lv/help](https://mt.lv/help) 您可以透過網頁瀏覽器中的 WebFig 或 "WinBox" 配置工具 [https://mt.lv/winbox](https://mt.lv/winbox) 配置裝置。**提供多種配置方式以確保可訪問性。** 要開始設定，請在網頁瀏覽器中開啟 192.168.88.1 開始配置。如果該 IP 地址不可用，請使用 WinBox 並選擇 "Neighbors" 標籤頁來查詢裝置。然後使用 MAC 地址進行連線。使用者名稱為 "admin"，沒有密碼（或者，對於某些型號，請檢視貼紙上的使用者和無線密碼）。本裝置配備一個 RJ45 序列埠，預設設定為 115200 bit/s、8 個數據位、1 個停止位、無校驗位。出於恢復目的，可以從網路重新安裝裝置，請參見 Reset 按鈕。

## 按鈕和跳線 {#buttons-and-jumpers}

**Reset 按鈕**：

- 在啟動期間按住此按鈕，直到 USER LED 燈開始閃爍，鬆開按鈕即可重設 RouterOS 配置。
- 按住 Reset 按鈕併為裝置通電（等待 "USER" LED 閃爍後變為穩定 "On"，當 "USER" LED 變為 "Off" 時鬆開 Reset 按鈕）——裝置將以 BOOTP 模式啟動，使用 [Netinstall](/docs/getting-started/installation-and-upgrade/netinstall) 重新安裝 RouterOS。**MGMT/BOOT 乙太網埠用於 Netinstall 過程。** 關於使用 Netinstall 恢復工具的說明，請參閱 RouterOS 文件。

無論使用上述哪種方式，如果在裝置通電之前按下按鈕，系統都將載入備份 RouterBOOT 載入程式。請在 LED 開始閃爍之前鬆開按鈕，以便只加載備份 RouterBOOT 而不進行重設。這對於 RouterBOOT 偵錯和恢復非常有用。

Mode 按鈕預設不起作用，但可以在 /system routerboard mode-button 選單中為其指定任意指令碼。

## LED {#leds}

本裝置有四個 LED 燈。PWR1/2 指示當前使用的是哪個電源。FAULT 指示散熱風扇出現問題。USER 可以透過軟體進行配置。
