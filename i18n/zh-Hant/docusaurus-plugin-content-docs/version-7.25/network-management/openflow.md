RouterOS 支援 OpenFlow [1.0](https://opennetworking.org/wp-content/uploads/2013/04/openflow-spec-v1.0.0.pdf) 和 [1.3](https://opennetworking.org/wp-content/uploads/2014/10/openflow-spec-v1.3.0.pdf)，它們允許 OpenFlow 控制器與 OpenFlow 代理之間進行通訊。

OpenFlow 用於在軟體定義網路（SDN）中集中管理網路裝置。

OpenFlow 控制器上的應用程式可以訪問交換器的資料通路，並執行自定義任務，例如流引導和流量監控。

控制器傳送要新增到代理流表中的流。封包查詢、修改和轉發基於代理的流表進行。

在不使用 "goto table" 流的簡單場景中，RouterOS 支援 OpenFlow 快速路徑。

OpenFlow 會覆蓋常規的封包處理。除非 OpenFlow 控制器設定了允許此操作的流，否則在作為 OpenFlow 交換器埠的介面上收到的封包不會經過常規網路協定棧。配置 OpenFlow 時，請注意不要停用對裝置的訪問。

OpenFlow 支援以獨立的 OpenFlow 軟體包形式提供。

## 支援的基本能力 {#supported-basic-capabilities}

- OFPC\_FLOW\_STATS
- OFPC\_TABLE\_STATS
- OFPC\_PORT\_STATS
- OFPC\_GROUP\_STATS

## 不支援的基本能力 {#unsupported-basic-capabilities}

- OFPC\_IP\_REASM
- OFPC\_QUEUE\_STATS
- OFPC\_PORT\_BLOCKED

## 不支援的配置引數和動作（版本 1） {#unsupported-configuration-parameters-and-actions-version-1}

- OFPAT\_SET\_NW\_SRC
- OFPAT\_SET\_NW\_DST
- OFPAT\_SET\_NW\_TOS
- OFPAT\_SET\_TP\_SRC
- OFPAT\_SET\_TP\_DST
- OFPAT\_ENQUEUE
- OFPAT\_VENDOR

## 不支援的配置引數和動作（版本 1.3） {#unsupported-configuration-parameters-and-actions-version-13}

- OFPT\_SET\_ASYNC
- OFPAT\_SET\_NW\_TTL
- OFPAT\_DEC\_NW\_TTL
- OFPAT\_COPY\_TTL\_OUT
- OFPAT\_COPY\_TTL\_IN

## 配置示例 {#configuration-example}

本示例演示了在 sfp-sfpplus1 和 sfp-sfpplus2 埠之間非常基礎的 L2 無標記封包轉發。使用 Faucet 作為控制器。

```routeros
/openflow
add controllers=tcp/10.155.101.182/6653 datapath-id=1/DC:2C:6E:A4:B4:2E disabled=no name=faucet

/openflow/port
add disabled=no interface=sfp-sfpplus1 port-id=1 switch=faucet
add disabled=no interface=sfp-sfpplus2 port-id=2 switch=faucet
```

:::info
如果你還打算使用 Gauge，請將 Gauge 的 IP 地址和埠新增到控制器列表中。在此示例中，6654 是 Gauge 埠：`controllers=tcp/10.155.101.182/6653,tcp/10.155.101.182/6654`
:::

在 Faucet 配置中，`dp_id` 必須與 RouterOS 配置中的 `datapath-id` 以十六進位制格式匹配（`1/DC:2C:6E:A4:B4:2E` → `0x0001dc2c6ea4b42e`）：

```routeros
---
vlans:
    100:
        description: "untagged"

acls:
    1:
        - rule:
            actions:
                allow: 1

dps:
    test_switch:
        dp_id: 0x0001dc2c6ea4b42e
        hardware: "Generic"
        drop_broadcast_source_address: false
        drop_spoofed_faucet_mac: false
        interfaces:
            1:
                name: "h1"
                description: "host1 container"
                native_vlan: 100
                acl_in: 1
            2:
                name: "h2"
                description: "host2 container"
                native_vlan: 100
                acl_in: 1

```

## 統計資訊 {#statistics}

可以從 `/openflow/print fast-path` 檢視快速路徑統計資訊。在此示例中，由於 Faucet 安裝的流較為複雜，快速路徑無法正常工作。

```routeros
[admin@CCR2004_2XS_111] /openflow> print fast-path 
  openflow-fast-path-packets: 0 0
    openflow-fast-path-bytes: 0 0
```

可以從 `/openflow/port` 選單檢視埠統計資訊。

```routeros
[admin@CCR2004_2XS_111] /openflow/port> print stats
Columns: INTERFACE, PORT-ID, RX-BYTES, TX-BYTES, RX-PACKETS, TX-PACKETS
```
