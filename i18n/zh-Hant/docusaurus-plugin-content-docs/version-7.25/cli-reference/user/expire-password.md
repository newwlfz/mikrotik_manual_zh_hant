## user/expire-password {#userexpire-password}
**型別：** 命令

使所選使用者的密碼過期（在 [`/user`](./index.md) 中設定 `E` 標誌）。在下一次互動式登入時，系統會要求使用者設定新密碼；使用 `/user/set` 設定新密碼也會清除該標誌。完整指南請參閱 [使用者](../../authentication-authorization-accounting/user.md)。
