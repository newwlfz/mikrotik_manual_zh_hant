## system/ntp/client/reset-freq-drift {#systemntpclientreset-freq-drift}
**型別：** 命令

將用戶端測得的本地時鐘頻率漂移重設為零，丟棄用戶端此前學到的校正值。隨著用戶端持續輪詢其伺服器，該估計值會被重新建立。請參閱 [NTP](../../../../system-information-and-utilities/ntp.md) 指南。
