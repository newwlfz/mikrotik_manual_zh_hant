## ip/dhcp-client/renew {#ipdhcp-clientrenew}
**型別：** 命令

立即續訂當前租約，無需等到租期過半。如果伺服器沒有響應，用戶端會繼續進行重新繫結，並保留其地址，直到租約到期。
