## ip/proxy/clear-cache {#ipproxyclear-cache}
**型別：** 命令

刪除 Web 代理快取中的所有物件。更改 [`/ip/proxy`](./index.md) 中的任何設定也會清除快取。關於快取的概述，請參閱 [Web 代理](../../../network-management/proxy/web-proxy.md)。
