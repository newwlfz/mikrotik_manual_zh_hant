6to4 是一種特殊機制，允許 IPv6 封包在未顯式配置隧道介面的情況下透過 IPv4 網路傳輸。它特別適用於透過不支援 IPv6 的網路連線兩個或多個 IPv6 網路。6to4 機制以兩種模式執行。如果未配置 *remote-address*，且前 16 位是 *2002*，則路由器會封裝 IPv6 封包並直接透過 IPv4 傳送，接下來的 32 位會被解釋為目標地址（轉換為十六進位制的 IPv4 地址）。另一種情況下，IPv6 封包會直接傳送到 IPv4 *remote-address*。

## 配置示例 {#configuration-examples}

### 簡單 6to4 隧道封裝（不工作） {#simple-6to4-tunnel-encapsulation-not-working}

![](/img/01fb25e7c82ced9c.webp)

可以使用 2002::/16 分配的地址空間，簡單地透過 IPv4 網路路由 IPv6 封包。所有 6to4 節點都必須具有可訪問的 IPv4 地址——如果你在 Internet 上執行此設定，則所有 IPv4 地址都必須是公網地址。

#### R1 配置 {#r1-configuration}

建立 6to4 隧道介面：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一個 IPv6 地址，其中前 16 位為 '2002'，接下來的 32 位為十六進位制格式的 IPv4。例如，如果路由器的 IP 地址是 10.0.1.1，則 IPv6 地址是 2002:A00:101::

```ros
/ipv6/address
add address=2002:a00:101::/128 advertise=no interface=6to4-tunnel1
```

新增一條透過 6to4-tunnel 介面指向專門分配的 6to4 隧道範圍的路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### R2 配置 {#r2-configuration}

建立 6to4 隧道介面：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一個按照與 R1 相同原則生成的 IPv6 地址。在此例中，10.0.2.1 轉換為 2002:A00:201::

```ros
/ipv6/address
add address=2002:a00:201::/128 advertise=no interface=6to4-tunnel1
```

這一側同樣需要 6to4 路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### 測試 {#testing}

配置兩臺裝置後，如果 IPv6 地址生成正確，應該可以 ping 通這些地址。

從 R1：

```ros
/ping 2002:a00:201::
```

### Hurricane Electric Tunnel Broker 示例 {#hurricane-electric-tunnel-broker-example}

本示例展示如何透過 6to4 隧道，經由 IPv4 網路在 RouterOS 裝置上獲得 IPv6 連線。

要建立隧道，你需要一個公網 IPv4 地址，並啟用來自 Tunnel Broker IPv4 伺服器的 ping。

當你使用 [Hurricane Electric Tunnel Broker](https://tunnelbroker.net) 建立隧道時，你會收到一個路由的 /64 IPv6 字首以及設定隧道所需的其他資訊。

*![](/img/0c5a58e7258874ec.webp)*

*本示例假設你的公網 IPv4 地址是 194.105.56.170*

Hurricane Electric 在 'Example Configurations' 部分提供了可直接用於 RouterOS 的命令：

```ros
/interface/6to4
add comment="Hurricane Electric IPv6 Tunnel Broker" disabled=no local-address=194.105.56.170 mtu=1280 name=sit1 remote-address=216.66.80.90
/ipv6/route
add comment="" disabled=no distance=1 dst-address=2000::/3 gateway=2001:470:27:37e::1 scope=30 target-scope=10
/ipv6/address
add address=2001:470:27:37e::2/64 advertise=no disabled=no eui-64=no interface=sit1
```

這些命令會設定隧道。隨後路由器可以連線到 IPv6 主機，但終端使用者裝置（計算機、平板電腦、手機）尚不具備 IPv6 連線。

要為用戶端分配 IPv6 地址，請將 Routed IPv6 Prefix 新增到內部介面（預設為 bridge-local）。

```ros
/ipv6/address/add address=2001:470:28:37e:: interface=bridge-local advertise=yes
```

透過網路發現啟用 DNS 伺服器通告。

```ros
/ipv6/nd/set [ find default=yes ] advertise-dns=yes
```

最後新增 IPv6 DNS 伺服器（這些是 Google 公共 DNS 伺服器，你也可以使用 Hurricane Electric 提供的伺服器 - 2001:470:20::2）。

```ros
/ip/dns/set allow-remote-requests=yes servers=2001:4860:4860::8888,2001:4860:4860::8844
```

在你的裝置上啟用 IPv6 後，使用 [https://test-ipv6.com](https://test-ipv6.com/) 測試 IPv6 連線。
