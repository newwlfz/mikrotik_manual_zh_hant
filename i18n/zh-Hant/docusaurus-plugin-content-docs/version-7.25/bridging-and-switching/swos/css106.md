## 功能 {#features}

| 功能 | 描述 |
| --- | --- |
| **轉發** | 全非阻塞線速交換；主機表中最多 2k 條 MAC 表項；轉發資料庫基於 SVL 或 IVL 工作；埠隔離；埠鎖定；Jumbo 幀支援 - 9198 bytes |
| **生成樹協定** | 支援 RSTP |
| **組播轉發** | 支援 IGMP Snooping |
| **映象** | 基於埠的映象 |
| **VLAN** | 完全相容 IEEE802。基於埠的 VLAN；VLAN 過濾 |
| **服務質量 (QoS)** | 入方向流量限制（透過 ACL）；出方向流量限制 |
| **Access Control List** | 入口 ACL 表；最多 32 條 ACL 規則（受 SwOS 限制）；基於埠、L2、L3、L4 協定頭欄位進行分類；ACL 動作包括過濾、轉發和修改協定頭欄位 |

## 連線到交換器 {#connecting-to-the-switch}

開啟 Web 瀏覽器，輸入交換器的 IP 地址（預設為 192.168.88.1），隨後會出現登入螢幕。交換器也可以執行 DHCP 用戶端，請檢查 DHCP 伺服器是否已分配其他 IP 地址。

![Swos login css106](/img/776fa0e1c75d6b6b.webp)

SwOS 預設 IP 地址：**192.168.88.1**，使用者名稱：**admin**，並且沒有密碼。

[鄰居發現](../../system-information-and-utilities/neighbor-discovery.md) 可用於發現 Mikrotik 交換器的 IP 地址。不支援 LLDP。

## 介面概覽 {#interface-overview}

SwOS 介面選單包含多個標籤頁：Link、SFP、Forwarding、RST、Statistics、Errors、VLAN、VLANs、Hosts、IGMP Groups、SNMP、ACL、System 和 Upgrade。

SwOS 配置工具中按鈕的說明：

- **Append** - 在列表末尾新增新項
- **Apply All** - 應用當前配置更改
- **Cut** - 從列表中刪除一項
- **Clear** - 重設該項的屬性
- **Discard Changes** - 移除未儲存的配置
- **Insert** - 新增新項到列表（放在當前項之前）
- **Sort** - 按 VLAN ID 對 VLAN 表排序；按 MAC 地址對主機表排序
- **Change Password** - 更改交換器密碼
- **Logout** - 從當前交換器登出
- **Reboot** - 重啟交換器
- **Reset Configuration** - 將配置重設為出廠預設值
- **Choose File** - 瀏覽升級或備份檔案
- **Upgrade** - 使用所選檔案升級交換器韌體
- **Download & Upgrade** - 自動嘗試下載並升級韌體，執行 Web 瀏覽器的 PC 應能訪問網際網路
- **Restore Backup** - 使用所選備份檔案恢復交換器
- **Save Backup** - 從交換器生成並下載備份檔案

> **注意：** 每個 RouterBOARD 交換器系列都有各自的韌體，不能安裝到其他系列型號上！CSS106-5G-1S（RB260GS）和 CSS106-1G-4P-1S（RB260GSP）支援 SwOS v2.0 及更高版本。升級裝置時，它會先載入主韌體，然後進行升級。如果選擇了錯誤的韌體檔案，裝置將繼續使用主韌體執行，你可以選擇正確的檔案。

## 系統 {#system}

System 標籤頁執行以下功能：

- 交換器的一般資訊
- 交換器管理
- 配置重設
- 備份和恢復配置

> **注意：** SwOS 使用簡單演算法來確保 TCP/IP 通訊——它只回複數據包來源的同一 IP 和 MAC 地址。這樣裝置本身就不需要預設閘道器。

![Swos system1](/img/923e82d8459140b1.webp)

| 屬性 | 描述 |
| --- | --- |
| **地址獲取** | 指定要使用的地址獲取方式：`DHCP with fallback` - 交換器嘗試從 DHCP 伺服器請求 IPv4 地址。如果請求不成功，則可以使用 **Static IP Address** 值訪問交換器`static` - 地址設定為 **Static IP Address** 值（僅 IPv4）`DHCP only` - 交換器使用 DHCPv4 用戶端獲取地址 |
| **Static IP Address** | 當 **Address Acquisition** 設定為 `DHCP with fallback` 或 `static` 時，交換器的 IP 地址 |
| **Identity** | 交換器名稱（用於 Mikrotik neighbor discovery protocol） |
| **Allow From** | 可訪問交換器的 IP 地址或網路。預設值為 `0.0.0.0/0` - 任意地址。 |
| **Allow From Ports** | 可訪問該服務的交換器埠列表 |
| **Allow From VLAN** | 可訪問該服務的 VLAN ID。請確保先配置 VLAN 和 VLAN 頁面 |
| **Watchdog** | 啟用或停用系統看門狗。發生故障情況時，它將重設交換器的 CPU |
| **Independent VLAN Lookup** | 啟用或停用主機表中的獨立 VLAN 查詢以進行封包轉發 |
| **IGMP Snooping** | 啟用或停用 IGMP Snooping |
| **IGMP Fast Leave** | 啟用或停用交換器埠上的 IGMP fast leave 功能。此屬性僅在啟用 IGMP Snooping 時生效 |
| **Mikrotik Discovery Protocol** | 啟用或停用 Mikrotik neighbor discovery protocol |
| **Port1 PoE In Long Cable** | 如果啟用，它將關閉所有 PoE 輸出埠上的短路檢測，以允許使用更長的乙太網線纜。這是一個潛在危險的設定，應謹慎使用。（CSS106-1G-4P-1S 型號） |
| **MAC Address** | 交換器的 MAC 地址（只讀） |
| **Serial Number** | 交換器的序列號（只讀） |
| **Board Name** | MikroTik 型號名稱（只讀） |
| **Voltage** | 顯示以伏特為單位的輸入電壓（只讀，CSS106-1G-4P-1S 型號） |
| **Temperature** | 顯示攝氏度溫標下的 PCB 溫度（只讀，CSS106-1G-4P-1S 型號） |

## 鏈路 {#link}

Link 標籤頁允許你：

- 配置乙太網和 SFP 埠
- 監控乙太網和 SFP 埠狀態

![Swos link css106](/img/04bcae8177929500.webp)

| 屬性 | 描述 |
| --- | --- |
| **Enabled** | 啟用或停用埠 |
| **Name** | 可編輯的埠名稱 |
| **Link Status** | 當前鏈路狀態（只讀） |
| **Auto Negotiation** | 啟用或停用自動協商（某些 SFP 模組可能需要停用它才能工作） |
| **Speed** | 指定埠的速度設定（要求停用自動協商） |
| **Full Duplex** | 指定埠的雙工模式（要求停用自動協商） |
| **Flow control** | 啟用或停用 802.3x 流控制 |

> **注意：** 使用 SFP+ 1m/3m DAC 電纜或 S-RJ01 模組時，即使另一端沒有連線任何裝置，裝置也始終顯示鏈路已建立。

交換器支援最大 9198 bytes 的 Jumbo 幀。SwOS 裝置不支援手動降低 MTU 設定。

### PoE {#poe}

PoE 設定會更改 CSS106-1G-4P-1S port2-port5 上的 Power over Ethernet 輸出，並顯示 PoE 狀態和測量值。

![740px Swospoe2](/img/edfe6029282de3b7.webp)

| 屬性 | 描述 |
| --- | --- |
| **PoE Out** | 設定埠的 PoE 輸出模式：`off` - 關閉所有檢測和 PoE 輸出；`auto` - 根據備用線對上的電阻進行檢測，以檢查埠是否具有 PoE 能力。要使埠開啟，測量值應在 3kΩ 到 26.5kΩ 範圍內；`on` - 無論埠上的電阻如何，都會啟用 PoE 輸出。***請謹慎使用，因為這可能損壞連線的裝置！***；`calibr` - 手動重新校準埠 PoE 輸出。如果為連線裝置供電時偶爾出現問題，可能需要執行此操作。 |
| **PoE Priority** | PoE 輸出供電的埠優先順序。如果安裝超出可用功率預算，優先順序最低的埠將首先關閉。`1` - 優先順序最高的埠；`4` - 優先順序最低的埠 |
| **PoE Status** | 埠當前的 PoE 輸出狀態：`disabled` - PoE 輸出已關閉；`waiting for load` - `auto` 模式檢測到超出範圍的電阻以開啟 PoE 輸出；`powered on` - PoE 輸出已開啟；`short circuit` - 如果檢測到短路，則關閉 PoE 輸出，以確保受電裝置不會受到額外損壞，供電裝置也不會損壞；`voltage too low` - 提供的電壓不足以透過 PoE 輸出開啟裝置；`current too low` - 提供的電流不足以透過 PoE 輸出開啟裝置；`waiting for cable disconnect` - 使用 `calibr` 進行手動重新校準已檢測到連線的裝置，並等待斷開連線以完成重新校準過程 |
| **PoE Current** | 顯示埠上的電流使用量，單位為 milliamperes |
| **PoE Power** | 顯示埠上的 PoE 輸出功率，單位為 watts |

## 轉發 {#forwarding}

Forwarding 標籤頁提供交換器埠之間的高階轉發選項、埠隔離、埠鎖定、埠映象和出方向頻寬限制功能。透過設定 `Rate`，可以使用[訪問控制列表](#acl)配置每個埠的入方向速率和廣播流量速率。ACL 必須為每個條目設定一個埠，才能正確提供頻寬限制。

![740px Swos forwarding2](/img/ca2d7131f8465cde.webp)

| 屬性 | 描述 |
| --- | --- |
| **Forwarding** | 轉發表 - 允許或限制特定埠之間的流量 |
| **Port Lock** | `Port Lock` - 啟用或停用此埠上的 MAC 地址學習。啟用該選項後，將限制 MAC 地址學習，應配置靜態 MAC 地址；`Lock On First` - 啟用或停用此埠上的 MAC 地址學習（仍會學習第一個接收封包的 MAC 地址） |
| **Port Mirroring** | `Mirror Ingress` - 進入此埠的流量是否必須複製並轉發到映象目標埠；`Mirror Egress` - 離開此埠的流量是否必須複製並轉發到映象目標埠；`Mirror To` - 映象目標埠 |
| **Bandwidth Limit** | `Egress Rate` - 限制離開此埠的流量（bps） |

## RSTP {#rstp}

RSTP 選單中提供每埠和全域性 RSTP 配置與監控。

![Swos RSTP css106](/img/001984d0b4ba3e55.webp)

| 屬性 | 描述 |
| --- | --- |
| **RSTP** | 啟用或停用該埠上的 STP/RSTP 功能 |
| **模式** | 顯示特定埠上的 STP/RSTP 功能模式（只讀）：`RSTP``STP` |
| **角色** | 顯示特定埠角色（只讀）：`root` - 朝向根網橋並將用於向根網橋轉發流量或從根網橋轉發流量的埠`alternate` - 朝向根網橋但不轉發流量的埠（根埠的備份）`backup` - 背向根網橋但不轉發流量的埠（非根埠的備份）`designated` - 背向根網橋並會轉發流量的埠`disabled` - 嚴格來說不屬於 STP 的埠（RSTP 功能已停用） |
| **根路徑開銷** | 顯示朝向根網橋的埠的根路徑開銷（只讀） |
| **Type** | `edge` - 不應接收任何 BPDU 的埠，應連線到終端站（只讀）；`point-to-point` - 在全雙工鏈路上執行的埠，可以是 STP 的一部分並處於轉發狀態（只讀） |
| **State** | 顯示每個埠狀態（只讀）：`forwarding` - 埠參與流量轉發並學習 MAC 地址，正在接收 BPDU；`discarding` - 埠不參與流量轉發且不學習 MAC 地址，正在接收 BPDU；`learning` - 埠不參與流量轉發，但正在學習 MAC 地址 |
| **網橋優先順序（十六進位制）** | 用於根網橋選擇的 RSTP 網橋優先順序 |
| **Port Cost Mode** | 根據鏈路速度自動檢測 RSTP 埠開銷有兩種方法。`short`：10G - 2；1G - 4；100M - 10；10M - 100；`long`：10G - 2000；1G - 20000；100M - 200000；10M - 2000000 |
| **轉發保留組播** | 是否轉發 **01:80:C2:00:00:0x** 範圍內的 IEEE 保留組播 MAC 地址。符合 R/M/STP 標準的交換器應避免轉發這些封包。如果啟用此設定，SwOS 將轉發保留組播 MAC 封包並停用 RSTP：- 交換器將不處理傳入的 BPDU（橋接協定資料單元）- 它也不會發送自己的 BPDU- 網橋優先順序和按埠的 RSTP 配置設定將不再有任何效果。啟用保留 MAC 地址的轉發可能影響依賴這些地址的某些協定。建議僅在絕對必要時才啟用轉發，例如在透明橋接配置中（例如延長長距離鏈路、將網橋用作介質轉換器或進行網路分析）。值得注意的 MAC 地址和協定示例（RouterOS 使用的）：`01:80:C2:00:00:00` - 生成樹協定（STP）`01:80:C2:00:00:01` - 乙太網流控`01:80:C2:00:00:02` - 鏈路聚合控制協定（LACP）`01:80:C2:00:00:03` - Dot1x 用戶端和伺服器`01:80:C2:00:00:08` - 生成樹協定（用於 802.1ad 網橋，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0D` - 多 VLAN 註冊協定（用於 802.1ad 網橋，使用 `ether-type=0x88a8`）`01:80:C2:00:00:0E` - 鏈路層發現協定、多機箱鏈路聚合組和精確時間協定流控 MAC 地址 `01:80:C2:00:00:01` 是一個例外 —— 它不會被 SwOS 轉發。 |
| **根網橋** | 網路中所選根網橋的優先順序和 MAC 地址（只讀） |

## VLAN 與 VLANs {#vlan-and-vlans}

交換器埠的 VLAN 配置。

![740px Swos vlan2](/img/5d51b5ec225f57e1.webp)

| 屬性 | 描述 |
| --- | --- |
| **VLAN Mode** | 入方向埠的 VLAN 模式：`disabled` - 不使用 VLAN 表；交換器忽略帶標籤封包的 VLAN 標籤部分；`optional` - 對於 VLAN 標籤 ID 不在 VLAN 表中的封包，就像沒有 VLAN 標籤的封包一樣處理；`enabled` - 丟棄 VLAN 標籤 ID 不在 VLAN 表中的封包。沒有 VLAN 標籤的封包會被視為帶有 `Default VLAN ID` 的帶標籤封包；`strict` - 與 `enabled` 相同，但還會檢查入站介面的 VLAN 支援（丟棄 VLAN 標籤 ID 和入方向埠不在 VLAN 表中的封包） |
| **VLAN Receive** | 定義入方向埠上允許的封包型別：`any` - 允許某個埠上的帶標籤和不帶標籤封包；`only tagged` - 僅允許帶有 VLAN 標籤的封包；`only untagged` - 僅允許不帶 VLAN 標籤的封包 |
| **Default VLAN ID** | 交換器將把不帶標籤的入方向封包和帶有 "Default VLAN ID" 標籤的入方向封包都視為帶有此 VLAN ID 的標籤。如果封包的 VLAN ID 與 "Default VLAN ID" 匹配，它也會用於移除出方向流量的標籤。只有在出方向埠指定了 `VLAN Header = add if missing` 時，才會新增 VLAN 標籤本身 |
| **Force VLAN ID** | 是否將 `Default VLAN ID` 應用於帶有 VLAN 標籤的傳入封包 |
| **VLAN Header** | `leave as is` - 如果存在 VLAN 頭，則保持不變；`always strip` - 如果存在 VLAN 頭，則從封包中移除；`add if missing` - 如果不存在 VLAN 頭，則將其新增到封包中（VLAN ID 將為入方向埠的 `Default VLAN ID`） |

> **注意：** 執行 SwOS 2.12 版本的 CSS106 裝置在埠上啟用 VLAN 過濾（VLAN Mode 為 **enabled** 或 **strict**）時可以過濾 RSTP BPDU 封包。對於 SwOS 2.13 版本，建議在 trunk 埠上將 VLAN Receive 設定為 **any**。

> **注意：** VLAN 模式 `enabled` 和 `strict` 要求 VLANs 表中存在 VLAN ID 1，以允許不帶標籤的流量訪問交換器本身。

VLAN 表指定具有 IEEE 802.1Q 標籤的封包的轉發規則。基本上，該表包含將特定 VLAN 標籤 ID 對映到一個或多個埠組的條目。帶有 VLAN 標籤的封包透過相應表項中設定的一個或多個埠離開交換器。VLAN 表與目標 MAC 查詢一起工作，以確定出方向埠。VLAN 表最多支援 250 個條目。

![Swos vlan css106](/img/cdfe40f140124a72.webp)

| 屬性 | 描述 |
| --- | --- |
| **VLAN ID** | 封包的 VLAN ID |
| **IVL** | 啟用或停用獨立 VLAN 學習（IVL） |
| **IGMP Snooping** | 啟用或停用已定義 VLAN 上的 IGMP Snooping。啟用後，交換器將監聽來自已定義 VLAN 的 IGMP Join 和 Leave 請求，並且僅將流量轉發到已從該 VLAN 傳送 IGMP 成員請求的埠。停用後，交換器將向所有 VLAN 成員埠泛洪組播流量。 |
| **Ports** | 每個埠針對每個 VLAN ID 都有單獨的 *VLAN header* 選項。取決於 *VLAN mode*，如果在此表中進行查詢，則封包的出方向動作由此選項處理。**VLAN tab** 中的出方向選項將被忽略。 |

### VLAN 配置示例 {#vlan-configuration-examples}

#### Trunk 和 Access 埠 {#trunk-and-access-ports}

![Access ports small](/img/d235e6fd5caac3d6.webp)

1. 在 System 選單中啟用獨立 VLAN 學習（IVL）。

![Css106 ivl](/img/69cce788e8633553.webp)

1. 在 VLANs 選單中新增 VLAN 條目，指定埠成員關係，並啟用 IVL。可以使用預設的 "leave as is" 埠設定；可以透過 "Default VLAN ID" 設定更改打標籤和移除標籤的行為，請參見下一步。

![Css access trunk vlans](/img/866c15add91965c4.webp)

1. 在 VLAN 選單中，在計劃的 access 埠（不帶標籤）上配置 Default VLAN ID，選擇正確的 VLAN Receive 設定（Port2 為 only tagged，Port3-5 為 only untagged），並啟用嚴格的 VLAN 過濾，以確保只有允許的 VLAN 可以透過這些埠。

![Css106 access vlan](/img/894c635777800fe4.webp)

> **注意：** 執行 SwOS 2.12 版本的 CSS106 裝置在埠上啟用 VLAN 過濾（VLAN Mode 為 **enabled** 或 **strict**）時可以過濾 RSTP BPDU 封包。對於 SwOS 2.13 版本，建議在 trunk 埠上將 VLAN Receive 設定為 **any**。

#### Trunk 和 Hybrid 埠 {#trunk-and-hybrid-ports}

![Hybrid ports small](/img/238fa201dac1535f.webp)

1. 在 System 選單中啟用獨立 VLAN 學習（IVL）。

![Css106 ivl 1](/img/69cce788e8633553.webp)

1. 在 VLANs 選單中新增 VLAN 條目，指定埠成員關係，並啟用 IVL。可以使用預設的 "leave as is" 埠設定；可以透過 "Default VLAN ID" 設定更改打標籤和移除標籤的行為，請參見下一步。

![Css hybrid vlan](/img/05a39054ed03bffb.webp)

1. 在 VLAN 選單中，在計劃的 hybrid 埠（用於不帶標籤的 VLAN）上配置 Default VLAN ID，選擇正確的 VLAN Receive 設定（Port2 為 only tagged，Port3-5 為 any），並啟用嚴格的 VLAN 過濾，以確保只有允許的 VLAN 可以透過這些埠。

![Css hybrid vlans](/img/b285dc0d4f377d42.webp)

> **注意：** 執行 SwOS 2.12 版本的 CSS106 裝置在埠上啟用 VLAN 過濾（VLAN Mode 為 **enabled** 或 **strict**）時可以過濾 RSTP BPDU 封包。對於 SwOS 2.13 版本，建議在 trunk 埠上將 VLAN Receive 設定為 **any**。

#### 管理訪問 {#management-access}

在此示例中，將建立 VLAN 200 上的交換器管理訪問。配置方案與 "**Trunk 和 Access 埠**" 相同，步驟 **1.、2.、3.** 完全相同。額外的 **第 4** 步需要在 System 選單中指定管理 VLAN ID。應用配置後，交換器將僅在 Port2 上響應帶標籤的 VLAN 200 封包，並在 Port3 上響應不帶標籤的封包。DHCP 用戶端也將在指定的 VLAN ID 中工作。

![Css106 system vlan](/img/ebd3dc6d62accb2d.webp)

> **警告：** 如果 VLAN 設定配置不正確，更改管理 VLAN 可能會完全停用對交換器管理的訪問。更改此設定之前，請儲存配置備份，並在管理訪問丟失時使用[重設](#reset)。

## 主機 {#hosts}

此表表示動態學習到的 MAC 地址到埠對映條目。它可以包含兩種條目：動態和靜態。動態條目會自動新增——這也稱為學習過程：當交換器從某個埠接收到封包時，它會將該封包的源 MAC 地址 X 以及接收到該封包的埠新增到主機表中，因此當帶有目標 MAC 地址 X 的封包進入時，它就知道應該將封包轉發到哪個埠。如果目標 MAC 地址不在主機表中，則它會將封包轉發到組中的所有埠（泛洪）。動態條目大約需要 5 分鐘超時。

CSS106 系列交換器支援 2048 個主機表條目。

![Swos hosts css106](/img/a579ada46273a14f.webp)

| 屬性 | 描述 |
| --- | --- |
| **Port** | 封包應轉發到的埠（只讀） |
| **MAC** | 學習到的 MAC 地址（只讀） |
| **VLAN ID** | 學習到的 VLAN ID（只讀） |

### 靜態主機 {#static-hosts}

如果已存在具有相同 MAC 地址的動態條目，靜態條目將取代動態條目。新增靜態條目還可以訪問附加功能。

![740px Swos static2](/img/b02ac39742098a2b.webp)

| 屬性 | 描述 |
| --- | --- |
| **Ports** | 封包應轉發到的埠 |
| **MAC** | MAC 地址 |
| **VLAN ID** | VLAN ID |
| **Drop** | 來自某些埠的具有特定 MAC 地址的封包可以被丟棄 |
| **Mirror** | 封包可以被克隆併發送到映象目標埠 |

## SNMP {#snmp}

SwOS 支援 SNMP v1 和 v2c（對 GetRequest、GetNextRequest 和 GetBulkRequest 的響應），並使用 IF-MIB、SNMPv2-MIB、BRIDGE-MIB 和 MIKROTIK-MIB（僅用於 health、PoE-out 和 SFP 診斷）。不支援 SNMP trap 和寫入 SwOS 配置。

可用的 SNMP 資料：

- 系統資訊
- 系統執行時間
- 埠狀態
- 介面統計
- 主機表資訊

![Swos snmp2](/img/f3b87569bbcad587.webp)

| 屬性 | 描述 |
| --- | --- |
| **Enabled** | 啟用或停用 SNMP 服務 |
| **Community** | SNMP 團體名稱 |
| **Contact Info** | NMS 的聯絡資訊 |
| **Location** | NMS 的位置資訊 |

## ACL {#acl}

訪問控制列表 (ACL) 規則表是一個非常強大的工具，可根據 L2、L3 和 L4 協定頭欄位條件進行線速封包過濾、轉發和 VLAN 打標籤。SwOS 允許你實施有限數量的訪問控制列表規則（32 條僅使用 L2 條件的簡單規則；16 條同時使用 L2 和 L3 條件的規則；或 8 條使用所有 L2、L3 和 L4 條件的高階規則）。每條規則包含條件部分和動作部分。

![740px Swos acl2](/img/0bd3d4c1437ed824.webp)

**條件引數**

| 屬性 | 描述 |
| --- | --- |
| **From** | 封包進入的埠 |
| **MAC Src** | 源 MAC 地址和掩碼 |
| **MAC Dst** | 目標 MAC 地址和掩碼 |
| **Ethertype** | 封裝在乙太網幀有效載荷中的協定 |
| **VLAN** | VLAN 頭是否存在：`any` / `present` / `not present` |
| **VLAN ID** | VLAN 標籤 ID |
| **Priority** | VLAN 標籤中的優先順序 |
| **IP Src** (IP/netmask:port) | 源 IPv4 地址、網路掩碼和 L4 埠號 |
| **IP Dst** (IP/netmask:port) | 目標 IPv4 地址、網路掩碼和 L4 埠號 |
| **Protocol** | IP 協定 |
| **DSCP** | IP DSCP 欄位 |

**動作引數**

| 屬性 | 描述 |
| --- | --- |
| **Redirect To** | 是否強制使用新的目標埠（如果啟用了 "Redirect To"，但未在 "Redirect To Ports" 中指定埠，則封包將被丟棄） |
| **Redirect To Ports** | 重定向目標埠 |
| **Mirror** | 克隆封包並將其傳送到映象目標埠 |
| **Rate** | 限制頻寬（bps） |
| **Set VLAN ID** | 如果存在 VLAN 標籤，則更改 VLAN 標籤 ID |
| **Priority** | 如果存在 VLAN 標籤，則更改 VLAN 標籤優先順序位 |

## 重設 {#reset}

CSS106-5G-1S 和 CSS106-1G-4P-1S 內建備份 SwOS 韌體，可在標準韌體損壞或升級失敗時載入：

- 在裝置啟動時按住 Reset 按鈕幾秒鐘將重設配置並載入備份韌體。
- 載入備份韌體後，可以使用 Web 瀏覽器連線到 192.168.88.1（或從 DHCP 伺服器租用的地址）並安裝新的 SwOS 韌體。
