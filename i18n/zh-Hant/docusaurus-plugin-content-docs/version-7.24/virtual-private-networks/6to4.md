**子選單：** `/interface/6to4`

## 屬性說明 {#property-description}

| 屬性 | 描述 |
| :-- | :-- |
| **clamp-tcp-mss** (*yes \| no*; 預設：**yes**) | 控制是否更改接收到的 TCP SYN 報文的 MSS 大小。啟用後，如果當前 MSS 大小超過隧道介面 MTU（考慮 TCP/IP 開銷），路由器將更改接收到的 TCP SYN 報文的 MSS 大小。接收到的封裝報文仍將包含原始 MSS，並且只有在解封裝後才會更改 MSS。 |
| **comment** (*string*; 預設值: ) | 介面的簡短描述。 |
| **disabled** (*yes \| no*; 預設：**no**) | 專案是否已停用。 |
| **dont-fragment** (*inherit \| no*; 預設值：**no**) | 是否在相關封包中包含 DF 位： *no* - 如有需要則分片，*inherit* - 使用原始封包的 Don't Fragment 標誌。  （不帶 Don't Fragment：inherit - 封包可能被分片）。 |
| **dscp** (*integer: 0-63*; 預設：**inherit**) | 報文的 DSCP 值。Inherited 選項表示 DSCP 值將從將要被封裝的報文中繼承。 |
| **ipsec-secret** (*string*; 預設值：) *[敏感](../getting-started/configuration-management/list-of-menus-with-sensitive-parameters.md)* | 指定 secret 後，路由器會向 remote-address 新增動態 IPsec 對等體，並使用預共享金鑰和策略（預設情況下 phase2 使用 sha1/aes128cbc）。 |
| **keepalive** (*integer[/time],integer 0..4294967295*; 預設：**0,0**) | 隧道 keepalive 引數設定時間間隔，在此期間即使隧道遠端斷開，隧道執行標誌也將保持。如果配置的時間和重試次數失敗，則移除介面執行標誌。引數按以下格式編寫：`KeepaliveInterval,KeepaliveRetries`，其中 `KeepaliveInterval` 是時間間隔，`KeepaliveRetries` 是重試次數。預設情況下 keepalive 處於停用狀態（0 秒，0 次重試）。 |
| **local-address** (*IP*; 預設：) | 報文的源地址，且位於路由器本地。 |
| **mtu** (*integer*; 預設：**auto**) | 三層最大傳輸單元。 |
| **name** (*string*; 預設：) | 介面名稱。 |
| **remote-address** (*IP*; 預設：) | 6to4 隧道遠端的 IP 地址。如果未指定，IPv4 地址將從 2002::/16 閘道器地址派生。 |

## 配置示例 {#configuration-examples}

### 簡單的 6to4 隧道封裝（目前不可用） {#simple-6to4-tunnel-encapsulation-currently-not-working}

![](/img/01fb25e7c82ced9c.webp)

透過利用 2002::/16 分配的地址空間，可以簡單地在 IPv4 網路上路由 IPv6 報文。所有 6to4 節點都必須具有可達的 IPv4 地址——如果您在網際網路上執行此設定，則所有 IPv4 地址都必須是公網地址。

#### R1 配置 {#r1-configuration}

建立 6to4 隧道介面：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一個 IPv6 地址，其中前 16 位為 '2002'，接下來的 32 位為十六進位制格式的 IPv4。例如，如果路由器的 IP 地址是 10.0.1.1，則 IPv6 地址是 2002:A00:101::

```ros
/ipv6/address
add address=2002:a00:101::/128 advertise=no interface=6to4-tunnel1
```

新增一條透過 6to4-tunnel 介面指向專門分配的 6to4 隧道範圍的路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### R2 配置 {#r2-configuration}

建立 6to4 隧道介面：

```ros
/interface/6to4
add name=6to4-tunnel1
```

分配一個按照與 R1 相同原則生成的 IPv6 地址。在此例中，10.0.2.1 轉換為 2002:A00:201::

```ros
/ipv6/address
add address=2002:a00:201::/128 advertise=no interface=6to4-tunnel1
```

這一側同樣需要 6to4 路由。

```ros
/ipv6/route
add dst-address=2002::/16 gateway=6to4-tunnel1
```

#### 測試 {#testing}

配置兩臺裝置後，如果 IPv6 地址生成正確，應該可以 ping 通這些地址。

從 R1：

```ros
/ping 2002:a00:201::
```

### Hurricane Electric Tunnel Broker 示例 {#hurricane-electric-tunnel-broker-example}

以下示例將展示如何透過 6to4 隧道，在 IPv4 網路上讓 RouterOS 裝置獲得 IPv6 連線性。

要能夠建立隧道，您必須擁有公網 IPv4 地址，並啟用來自 Tunnel Broker IPv4 伺服器的 ping。

當您使用 [Hurricane Electric Tunnel Broker](https://tunnelbroker.net) 建立隧道時，您將獲得一個已路由的 /64 IPv6 字首以及設定隧道所需的其他資訊。

*![](/img/0c5a58e7258874ec.webp)*

*本示例假定您的公網 IPv4 地址是 194.105.56.170*

Hurricane Electric 在 '示例配置' 部分提供了可直接用於 RouterOS 的命令：

```ros
/interface/6to4
add comment="Hurricane Electric IPv6 Tunnel Broker" disabled=no local-address=194.105.56.170 mtu=1280 name=sit1 remote-address=216.66.80.90
/ipv6/route
add comment="" disabled=no distance=1 dst-address=2000::/3 gateway=2001:470:27:37e::1 scope=30 target-scope=10
/ipv6/address
add address=2001:470:27:37e::2/64 advertise=no disabled=no eui-64=no interface=sit1
```

這些命令將設定隧道本身——路由器將能夠連線到 IPv6 主機，但終端使用者裝置（計算機、平板電腦、手機）尚不具備 IPv6 連線性。

要能夠為用戶端分配 IPv6 地址，您必須將 Routed IPv6 Prefix 新增到內部介面（預設為 bridge-local）。

```ros
/ipv6/address/add address=2001:470:28:37e:: interface=bridge-local advertise=yes
```

透過網路發現啟用 DNS 伺服器通告

```ros
/ipv6/nd/set [ find default=yes ] advertise-dns=yes
```

最後新增 IPv6 DNS 伺服器（這些是 Google 公共 DNS 伺服器，您也可以使用 Hurricane Electric 提供的 2001:470:20::2）。

```ros
/ip/dns/set allow-remote-requests=yes servers=2001:4860:4860::8888,2001:4860:4860::8844
```

之後在您的裝置上啟用 IPv6，您就應該具備 IPv6 連線性。[https://test-ipv6.com](https://test-ipv6.com/) 可用於測試 IPv6 連線性。
