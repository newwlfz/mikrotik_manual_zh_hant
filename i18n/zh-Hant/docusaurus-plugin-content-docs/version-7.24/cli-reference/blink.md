## blink {#blink}
**條件：** !i386
**型別：** 命令

根據裝置型號，使裝置上的其中一個 LED 閃爍。通常為 USR LED。

<ArgTableRow arg="duration" typ="time">閃爍持續時間，以秒為單位</ArgTableRow>
</ArgTable>
