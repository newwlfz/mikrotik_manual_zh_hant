### 概述 {#summary}

**Quickset** 是一個簡單的配置嚮導頁面，只需點選幾下即可完成路由器配置。當用戶在 Web 瀏覽器中開啟預設 IP 地址 192.168.88.1 時，首先看到的就是此頁面。

Quickset 適用於所有具有某種出廠預設配置的裝置。沒有配置的裝置必須手動配置。最受歡迎且推薦的模式是 HomeAP（或 HomeAP dual，具體取決於裝置）。此 Quickset 模式為家庭使用者提供最簡單的術語和最常用的選項。

### 模式 {#modes}

根據路由器型號，Quickset 下拉選單中可能會提供不同的 Quickset 模式：

- **CAP**：受控接入點，一種將由集中式 CAPsMAN 伺服器管理的 AP 裝置。僅在已設定 CAPsMAN 伺服器時使用。
- **CPE**：用戶端裝置，它將連線到接入點 (AP) 裝置。提供掃描所在區域 AP 裝置的選項。
- **HomeAP**：大多數家庭使用者預設的接入點配置頁面。提供更少的選項和簡化的術語。
- **HomeAP dual**：雙頻裝置（2GHz/5GHz）。大多數家庭使用者預設的接入點配置頁面。提供更少的選項和簡化的術語。
- **Home Mesh**：用於組建更大的 WiFi 網路。啟用路由器中的 CAPsMAN 伺服器，並將本地 WiFi 介面置於 CAPsMAN 控制之下。只需在按住復位按鈕的情況下啟動其他 MikroTik WiFi AP，它們就會加入此 HomeMesh 網路（詳情請參閱其快速指南）。
- **PTP Bridge AP**：當需要在同一網路中透明地互連兩個遠端位置時，將一臺裝置設定為該模式，並將另一臺裝置設定為下一個模式（PTP Bridge CPE）。
- **PTP Bridge CPE**：當需要在同一網路中透明地互連兩個遠端位置時，將一臺裝置設定為該模式，並將另一臺裝置設定為上一個模式（PTP Bridge AP）。
- **WISP AP**：與 HomeAP 模式類似，但提供更高階的選項，並使用行業標準術語，例如 SSID 和 WPA。

### HomeAP {#homeap}

如果您想快速配置家庭接入點，應使用該模式。

#### 無線 {#wireless}

在此部分設定您的無線網路：

- **網路名稱**：您的智慧手機將如何顯示您的網路？在此設定任意您喜歡的名稱。在 HomeAP dual 中，您可以將 2GHz（傳統）和 5GHz（現代）網路設定為相同或不同的名稱（見 FAQ）。可使用任意格式的任意名稱。
- **頻率**：通常可以保留 “Auto”，這樣路由器會掃描環境並選擇佔用最少的通道（該操作只執行一次）。如果需要試驗，可使用自定義選擇。
- **頻段**：通常保留預設值（2GHz b/g/n 和 5GHz A/N/AC）。
- **使用訪問列表 (ACL)**：如果您希望根據使用者的 MAC（硬體）地址限制誰可以連線到您的 AP，請啟用此選項。要使用此選項，首先需要允許這些用戶端連線，然後使用下方 “Copy to ACL” 按鈕。這會將選中的用戶端複製到訪問列表。構建訪問列表 (ACL) 後，您可以啟用此選項，禁止其他任何人嘗試連線到您的裝置。通常可以保持此選項不變，因為無線密碼已提供所需的限制。
- **WiFi 密碼**：此處最重要的選項。設定一個安全密碼，同時加密您的無線通訊；連線無線網路時需要用到該密碼。
- **WPS 接受**：使用此按鈕可授予支援 WPS 連線模式的特定裝置訪問許可權。適用於印表機和其他難以輸入密碼的外圍裝置。首先在用戶端裝置中啟動 WPS 模式，然後在此處單擊一次 WPS 按鈕以允許該裝置。該按鈕僅工作幾秒鐘，並且按用戶端逐個操作。
- **訪客網路**：適用於無需知道您主 WiFi 密碼的家中訪客。可在此選項中為他們設定單獨的密碼。重要！訪客使用者將無法訪問您 LAN 中的其他裝置以及其他訪客裝置。此模式會啟用 Bridge 過濾器來阻止此類訪問。
- **無線用戶端**：此表顯示當前連線的用戶端裝置（其 MAC 地址、是否在您的訪問列表中、最後使用的 IP 地址、連線時長、以 dBm 表示的訊號強度以及條形圖）。

#### 網際網路 {#internet}

- **埠**：選擇哪個埠連線到 ISP（網際網路）調變解調器。通常是 Eth1。
- **地址獲取**：選擇 ISP 如何向您提供 IP 地址。請向您的服務提供商諮詢此選項以及其他選項（IP 地址、子網掩碼、閘道器）。
- **MAC 地址**：通常不應更改，除非您的 ISP 已將您繫結到特定 MAC 地址，並且您已將路由器更換為新路由器。
- **路由器防火牆**：這會為您的路由器和網路啟用安全防火牆。請始終確保選中此複選框，以免從網際網路埠訪問您的裝置。
- **MAC 伺服器 / MAC Winbox**：允許從 LAN 埠側以 MAC 地址模式使用 [Winbox 實用工具](https://mt.lv/winbox) 進行連線。當 IP 模式不可用時，可用於偵錯和恢復。僅供高階使用者使用。
- **發現**：允許其他 RouterOS 裝置透過型號名稱識別此裝置。

#### 本地網路 {#local-network}

- **IP 地址**：大多數情況下可保留預設值 192.168.88.1，除非您的路由器位於另一臺路由器之後。為避免 IP 衝突，請改為 192.168.89.1 或類似地址。
- **子網掩碼**：大多數情況下可保留 255.255.255.0。
- **橋接所有 LAN 埠**：允許您的裝置相互通訊，例如，即使您的電視透過乙太網 LAN 線纜連線，而您的 PC 透過 WiFi 連線。
- **DHCP 伺服器**：通常，您會希望家庭網路自動配置 IP 地址，因此請將 DHCP 設定保持為開啟並保留預設值。
- **NAT**：僅當您的 ISP 為路由器和本地網路都提供了公網 IP 地址時，才關閉此選項。否則，請保持 NAT 開啟。
- **UPnP**：此選項會為受支援的程式和裝置（例如您的 NAS 磁碟和點對點實用工具）啟用自動埠轉發（有些人稱之為“向本地網路開放埠”）。請謹慎使用，因為此選項有時會在您不知情的情況下將內部裝置暴露到網際網路。僅在明確需要時啟用。

#### VPN {#vpn}

如果您想從網際網路訪問本地網路（以及路由器），請使用安全的 VPN 隧道。此選項會為您提供一個可連線的域名，並啟用 PPTP 和 L2TP/IPsec（推薦使用後者）。使用者名稱為 'vpn'，您可以指定自己的密碼。您只需在此處啟用它，然後在筆記型電腦或手機上提供地址、使用者名稱和密碼；連線到 VPN 後，您將獲得通往家庭網路的安全加密連線。旅行時也很有用——您將能夠透過安全線路瀏覽網際網路，就像從家中連線一樣。這也有助於避開某些國家/地區設定的地理限制。

#### 系統 {#system}

- **檢查更新**：請始終使用此按鈕確保您的裝置保持最新。它會檢查是否有可用的 RouterOS 更新版本，並安裝該更新。
- **密碼**：用於設定裝置配置頁面本身的密碼。請確保任何人都無法訪問您的路由器配置頁面並更改設定。

### 常見問題解答 {#faq}

#### 問：Quickset 與 Webfig 標籤頁（其中會出現許多新選單）有何不同？ {#q-how-is-quickset-different-from-the-webfig-tab-where-a-bunch-of-new-menus-appear}

答：QuickSet 面向只需要讓裝置快速執行起來的新使用者。它在一個位置提供最常用的選項。如果您需要更多選項，請完全不要使用任何 QuickSet 設定；單擊 “Webfig” 開啟高階配置介面。完整功能將被解鎖。

#### 問：我可以同時使用 Quickset 和 Webfig 嗎？ {#q-can-i-use-quickset-and-webfig-together}

答：如果您打算使用 Quickset，就只使用 Quickset，反之亦然。雖然可以透過這種方式配置不衝突的設定，但不建議混用這些選單。Router 模式和 Bridge 模式有什麼區別？Bridge 模式會將所有介面加入網橋，允許轉發二層封包（充當集線器/交換器）。在 Router 模式下，封包透過使用 IP 地址和 IP 路由在三層轉發（充當路由器）。

#### 問：在 HomeAP 模式下，2GHz 和 5GHz 網路名稱應該相同還是不同？ {#q-in-homeap-mode-should-the-2ghz-and-5ghz-network-names-be-the-same-or-different}

答：如果您希望所有用戶端裝置（例如電視、手機、遊戲主機）都自動選擇最合適的網路，請將名稱設定為相同。如果您想強制某個用戶端裝置使用更快的 5GHz 802.11ac 連線，請將名稱設定為不同。

#### 問：我可以建立沒有安全設定的 AP（無密碼），或者在使用 QuickSet 時連線到這樣的 AP 嗎？ {#q-can-i-create-an-ap-without-security-settings---no-password-or-connect-to-such-ap-while-using-quickset}

答：QuickSet 預設使用 WPA2 預共享金鑰。這意味著最小密碼長度為 8 個字元，並且裝置只能連線到受 WPA2 保護的 AP，或自身充當 AP。對於沒有安全設定的配置，您需要使用 WinBox、Webfig 或控制檯手動配置。
