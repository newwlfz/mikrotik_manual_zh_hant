| 功能 | 說明 |

## 連線至交換器 {#connecting-to-the-switch}

開啟網頁瀏覽器並輸入交換器的 IP 位址（預設為 192.168.88.1），就會出現登入畫面。交換器也可以執行 DHCP 用戶端，請確認 DHCP 伺服器是否指派了不同的 IP 位址。

![Swos login css106](/img/776fa0e1c75d6b6b.webp)

SwOS 預設 IP 位址：**192.168.88.1**，使用者名稱：**admin**，且沒有密碼。

[MikroTik Neighbor Discovery](/docs/system-information-and-utilities/neighbor-discovery) 可用於探索 Mikrotik 交換器的 IP 位址。不支援 LLDP。

## 介面概觀 {#interface-overview}

SwOS 介面選單由數個標籤頁組成：Link、SFP、Forwarding、RST、Statistics、Errors、VLAN、VLANs、Hosts、IGMP Groups、SNMP、ACL、System 與 Upgrade。

SwOS 設定工具中按鈕的說明：

- **Append** - 在清單結尾新增項目
- **Apply All** - 套用目前的設定變更
- **Cut** - 從清單中移除項目
- **Clear** - 重設項目的屬性
- **Discard Changes** - 移除未儲存的設定
- **Insert** - 在清單中新增項目（放在目前項目之前）
- **Sort** - 依 VLAN-ID 排序 VLAN 表；依 MAC 位址排序主機表
- **Change Password** - 變更交換器的密碼
- **Logout** - 登出目前交換器
- **Reboot** - 重新啟動交換器
- **Reset Configuration** - 將設定重設回原廠預設值
- **Choose File** - 瀏覽升級或備份檔案
- **Upgrade** - 使用所選檔案升級交換器的韌體
- **Download & Upgrade** - 自動嘗試下載並升級韌體，執行網頁瀏覽器的電腦必須能存取網際網路
- **Restore Backup** - 使用所選備份檔案還原交換器
- **Save Backup** - 從交換器產生並下載備份檔案

> **Note:** 每個 RouterBOARD 交換器系列都有各自的韌體，無法安裝在其他系列型號上！CSS106-5G-1S (RB260GS) 與 CSS106-1G-4P-1S (RB260GSP) 支援 SwOS v2.0 及更新版本。升級設備時，會先載入主要韌體，然後進行升級。如果選擇了錯誤的韌體檔案，設備將繼續使用主要韌體運作，且你將能夠選擇正確的檔案。

## Forwarding

Forwarding 標籤提供交換器埠之間進階的轉送選項，包括埠隔離、埠鎖定、埠鏡像與輸出頻寬限制功能。每埠的輸入速率與廣播流量速率可透過 [Access Control List](#acl) 設定 `Rate` 來設定。ACL 每個項目必須只有一個埠，才能正確提供頻寬限制。

![740px Swos forwarding2](/img/ca2d7131f8465cde.webp)

| 屬性 | 說明 |
| --- | --- |
| **Forwarding** | 轉送表 - 允許或限制特定埠之間的流量流動 |
| **Port Lock** | <code>Port Lock</code> - 啟用或停用此埠的 MAC 位址學習。啟用此選項時，將限制 MAC 位址學習，並應設定靜態 MAC 位址<br/><code>Lock On First</code> - 啟用或停用此埠的 MAC 位址學習（仍會學習第一個接收封包的 MAC 位址） |
| **Port Mirroring** | <code>Mirror Ingress</code> - 進入此埠的流量是否必須複製並轉送至鏡像目標埠<br/><code>Mirror Egress</code> - 離開此埠的流量是否必須複製並轉送至鏡像目標埠<br/><code>Mirror To</code> - 鏡像目標埠 |
| **Bandwidth Limit** | `Egress Rate` - 限制離開此埠的流量（bps） |

| **Root Bridge** | 網路中所選根橋接器的優先順序與 MAC 位址（唯讀） |

## VLAN 與 VLAN {#vlan-and-vlans}

交換器埠的 VLAN 設定。

![740px Swos vlan2](/img/5d51b5ec225f57e1.webp)

| Property | Description |
| --- | --- |
| **VLAN Mode** |  ingress 埠的 VLAN 模式：<br/><code>disabled</code> - 不使用 VLAN 表；交換器會忽略封包中標記的 VLAN tag 部分<br/><code>optional</code> - 將 VLAN tag ID 未存在於 VLAN 表中的封包，視為沒有 VLAN tag 的封包處理<br/><code>enabled</code> - 丟棄 VLAN tag ID 未存在於 VLAN 表中的封包。沒有 VLAN tag 的封包會被視為帶有 <code>Default VLAN ID</code> 的標記封包<br/><code>strict</code> - 與 <code>enabled</code> 相同，但也會檢查傳入介面是否支援 VLAN（丟棄 VLAN tag ID 與 ingress 埠未存在於 VLAN 表中的封包） |
| **VLAN Receive** | 定義 ingress 埠允許的封包類型：<br/><code>any</code> - 允許特定埠上有標記與未標記的封包<br/><code>only tagged</code> - 只允許具有 VLAN tag 的封包<br/><code>only untagged</code> - 只允許沒有 VLAN tag 的封包 |
| **Default VLAN ID** | 交換器會將未標記以及標記為「Default VLAN ID」的 ingress 封包，視為以此 VLAN ID 標記。若封包的 VLAN ID 符合「Default VLAN ID」，也會用來移除 egress 流量的標記。只有當 egress 埠指定 `VLAN Header = add if missing` 時，才會加入 VLAN tag 本身 |
| **Force VLAN ID** | 是否將 `Default VLAN ID` 套用至具有 VLAN tag 的傳入封包 |
| **VLAN Header** | <code>leave as is</code> - 若存在 VLAN header，則保持不變<br/><code>always strip</code> - 若存在 VLAN header，則從封包中移除<br/><code>add if missing</code> - 若不存在 VLAN header，則加入封包（VLAN ID 將是 ingress 埠的 <code>Default VLAN ID</code>） |

> **注意：** 執行 SwOS 2.12 版的 CSS106 設備，在埠上啟用 VLAN 過濾時（VLAN Mode 為 **enabled** 或 **strict**），可以過濾 RSTP BPDU 封包。使用 SwOS 2.13 版時，建議在 trunk 埠上將 VLAN Receive 設為 **any**。

> **注意：** VLAN 模式 `enabled` 與 `strict` 需要 VLAN 表中有 VLAN ID 1，才能讓未標記流量存取交換器本身。

VLAN 表會指定具有 IEEE 802.1Q tag 封包的轉送規則。基本上，此表包含的項目會將特定 VLAN tag ID 對應至一組一個或多個埠。具有 VLAN tag 的封包會透過對應表項目中設定的一個或多個埠離開交換器。VLAN 表會與目的地 MAC 查閱搭配運作，以決定 egress 埠。VLAN 表最多支援 250 個項目。

![Swos vlan css106](/img/cdfe40f140124a72.webp)

| Property | Description |
| --- | --- |
| **VLAN ID** | 封包的 VLAN ID |
| **IVL** | 啟用或停用獨立 VLAN 學習（IVL） |
| **IGMP Snooping** | 在指定的 VLAN 上啟用或停用 IGMP Snooping。啟用時，交換器會監聽來自指定 VLAN 的 IGMP Join 與 Leave 要求，並且只將流量轉送至已從指定 VLAN 傳送 IGMP membership 要求的埠。停用時，交換器會將 Multicast 流量泛送至所有 VLAN 成員埠。 |
| **Ports** | 每個埠對每個 VLAN ID 都有個別的 *VLAN header* 選項。視 *VLAN mode* 而定，若在此表中進行查閱，封包的 egress 動作會由此選項處理。**VLAN tab** 中的 egress 選項會被忽略。 |

### VLAN 設定範例 {#vlan-configuration-examples}

#### Trunk 與 Access 埠 {#trunk-and-access-ports}

![Access ports small](/img/d235e6fd5caac3d6.webp)

1. 在 System 選單中啟用 independent VLAN learning（IVL）。

![Css106 ivl](/img/69cce788e8633553.webp)

1. 在 VLANs 選單中新增 VLAN 項目，指定埠成員並啟用 IVL。可使用預設的「leave as is」埠設定；標記與取消標記的行為可透過「Default VLAN ID」設定變更，請見下一步。

![Css access trunk vlans](/img/866c15add91965c4.webp)

1. 在 VLAN 選單中，於預計作為 access 的埠上設定 Default VLAN ID（untagged），選擇正確的 VLAN Receive 設定（Port2 only tagged、Port3-5 only untagged），並啟用 strict VLAN filtering，以確保只有允許的 VLAN 能通過這些埠。

![Css106 access vlan](/img/894c635777800fe4.webp)

> **注意：** 執行 SwOS 2.12 版的 CSS106 設備，在埠上啟用 VLAN filtering 時（VLAN Mode 為 **enabled** 或 **strict**）可以過濾 RSTP BPDU 封包。使用 SwOS 2.13 版時，建議在 trunk 埠上將 VLAN Receive 設為 **any**。

#### Trunk 與 Hybrid 埠 {#trunk-and-hybrid-ports}

![Hybrid ports small](/img/238fa201dac1535f.webp)

1. 在 System 選單中啟用 independent VLAN learning（IVL）。

![Css106 ivl 1](/img/69cce788e8633553.webp)

1. 在 VLANs 選單中新增 VLAN 項目，指定埠成員並啟用 IVL。可使用預設的「leave as is」埠設定；標記與取消標記的行為可透過「Default VLAN ID」設定變更，請見下一步。

![Css hybrid vlan](/img/05a39054ed03bffb.webp)

1. 在 VLAN 選單中，於預計作為 hybrid 的埠上設定 Default VLAN ID（用於 untagged VLAN），選擇正確的 VLAN Receive 設定（Port2 僅限 tagged，Port3-5 為 any），並啟用 strict VLAN filtering，以確保只有允許的 VLAN 能通過這些埠。

![Css hybrid vlans](/img/b285dc0d4f377d42.webp)

> **Note:** 執行 SwOS 2.12 版的 CSS106 設備，在埠上啟用 VLAN filtering 時（VLAN Mode 為 **enabled** 或 **strict**），可以過濾 RSTP BPDU 封包。使用 SwOS 2.13 版時，建議在 trunk 埠上將 VLAN Receive 設為 **any**。

#### 管理存取 {#management-access}

在此範例中，將建立透過 VLAN 200 存取交換器管理功能的方式。設定架構與「**Trunk and Access Ports**」相同，且步驟 **1.、2.、3.** 一致。額外的第 **4** 步需要在 System 選單中指定管理 VLAN ID。套用設定後，交換器只會回應 Port2 上 tagged VLAN 200 的封包，以及 Port3 上的 untagged 封包。DHCP 用戶端也會在指定的 VLAN ID 中運作。

![Css106 system vlan](/img/ebd3dc6d62accb2d.webp)

> **Warning:** 如果 VLAN 設定不正確，變更管理 VLAN 可能會完全無法存取交換器管理功能。變更此設定前請儲存設定備份，若遺失管理存取權，請使用 [Reset](#reset)。

## Hosts

此表格代表動態學習到的 MAC 位址與埠對應項目。它可以包含兩種類型的項目：動態與靜態。動態項目會自動新增，這也稱為學習程序：當交換器從某個埠收到封包時，它會將封包的來源 MAC 位址 X 及收到封包的埠新增到 host table，因此當封包的目的 MAC 位址為 X 時，交換器便知道應將封包轉送至哪個埠。如果目的 MAC 位址不在 host table 中，交換器會將封包轉送至群組中的所有埠（flood）。動態項目約 5 分鐘後逾時。

CSS106 系列交換器支援 2048 個 host table 項目。

![Swos hosts css106](/img/a579ada46273a14f.webp)

| Property | Description |
| --- | --- |
| **Port** | 封包應轉送至的埠（唯讀） |
| **MAC** | 已學習到的 MAC 位址（唯讀） |
| **VLAN ID** | 已學習到的 VLAN ID（唯讀） |

### 靜態主機 {#static-hosts}

如果已存在具有相同 MAC 位址的動態項目，靜態項目將會取代動態項目。新增靜態項目也可使用其他功能。

![740px Swos static2](/img/b02ac39742098a2b.webp)

| 屬性 | 說明 |
| --- | --- |
| **Ports** | 封包應轉送至的埠 |
| **MAC** | MAC 位址 |
| **VLAN ID** | VLAN ID |
| **Drop** | 可捨棄從特定埠傳入且具特定 MAC 位址的封包 |
| **Mirror** | 可複製封包並傳送至 mirror-target 埠 |

## SNMP

SwOS 支援 SNMP v1 與 v2c（回應 GetRequest、GetNextRequest 與 GetBulkRequest），並使用 IF-MIB、SNMPv2-MIB、BRIDGE-MIB 與 MIKROTIK-MIB（僅用於健康狀態、PoE-out 與 SFP 診斷）。不支援 SNMP trap 與寫入 SwOS 設定。

可用的 SNMP 資料：

- 系統資訊
- 系統運行時間
- 埠狀態
- 介面統計資訊
- 主機表資訊

![Swos snmp2](/img/f3b87569bbcad587.webp)

| 屬性 | 說明 |
| --- | --- |
| **Enabled** | 啟用或停用 SNMP 服務 |
| **Community** | SNMP community 名稱 |
| **Contact Info** | NMS 的聯絡資訊 |
| **Location** | NMS 的位置資訊 |

## ACL

存取控制清單（ACL）規則表是非常強大的工具，可根據 L2、L3 與 L4 協定標頭欄位條件，以線速進行封包過濾、轉送與 VLAN 標記。SwOS 可讓你實作有限數量的存取控制清單規則（32 條簡單規則，僅使用 L2 條件；16 條規則，同時使用 L2 與 L3 條件；或 8 條進階規則，使用所有 L2、L3 與 L4 條件）。每條規則都包含條件部分與動作部分。

![740px Swos acl2](/img/0bd3d4c1437ed824.webp)

**條件參數**

| 屬性 | 說明 |
| --- | --- |
| **From** | 封包進入的埠 |
| **MAC Src** | 來源 MAC 位址與遮罩 |
| **MAC Dst** | 目的 MAC 位址與遮罩 |
| **Ethertype** | 封裝在 Ethernet Frame 酬載中的協定 |
| **VLAN** | VLAN 標頭是否存在：`any` / `present` / `not present` |
| **VLAN ID** | VLAN 標籤 ID |
| **Priority** | VLAN 標籤中的優先順序 |
| **IP Src** (IP/netmask:port) | 來源 IPv4 位址、網路遮罩與 L4 埠號 |
| **IP Dst** (IP/netmask:port) | 目的 IPv4 位址、網路遮罩與 L4 埠號 |
| **Protocol** | IP 協定 |
| **DSCP** | IP DSCP 欄位 |

**動作參數**

| 屬性 | 說明 |
| --- | --- |
| **Redirect To** | 是否強制使用新的目的埠（若啟用「Redirect To」，但「Redirect To Ports」未指定任何埠，封包將會被丟棄） |
| **Redirect To Ports** | 重新導向目的埠 |
| **Mirror** | 複製封包並將其傳送至 mirror-target 埠 |
| **Rate** | 限制頻寬（bps） |
| **Set VLAN ID** | 若存在 VLAN 標籤，則變更 VLAN 標籤 ID |
| **Priority** | 若存在 VLAN 標籤，則變更 VLAN 標籤優先權位元 |

## Reset

CSS106-5G-1S 與 CSS106-1G-4P-1S 內建備援 SwOS 韌體，可在標準韌體損毀或升級失敗時載入：

- 在設備開機時按住 Reset 按鈕幾秒，將會重設設定並載入備援韌體。
- 載入備援韌體後，可使用網頁瀏覽器連線至 192.168.88.1（或由 DHCP 伺服器提供的租用位址），並安裝新的 SwOS 韌體。
