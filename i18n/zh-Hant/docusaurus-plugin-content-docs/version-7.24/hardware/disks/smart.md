:::info
此功能需要 [儲存](../../storage/index.md) 軟體包。
:::

從 RouterOS 7.23 開始，已新增 S.M.A.R.T.（自我監測、分析和報告技術）支援。

S.M.A.R.T. 是現代儲存驅動器內建的監控系統，可用於監控驅動器的健康狀況、效能和錯誤率。
對於任何支援 S.M.A.R.T. 的已連線儲存裝置，你可以使用 `/disk smart-info` 命令直接從 CLI 檢索診斷屬性。

:::info

某些 USB 硬碟盒可能不支援檢索 S.M.A.R.T 資訊。

:::
