Cloud Hosted Router (CHR) 是 RouterOS 的虛擬化版本，旨在運行於 x86_64 虛擬環境。它提供與 MikroTik 硬體裝置相同的核心路由、防火牆、VPN 和管理功能。

本節介紹 CHR 的安裝、部署和許可。
