## ip/proxy/direct/reset-counters {#ipproxydirectreset-counters}
**型別：** 命令

重設 [`/ip/proxy/direct`](./index.md) 中給定規則的 `hits` 計數器，例如 `/ip/proxy/direct/reset-counters [find comment=test]`。有關概述，請參閱 [Web 代理](../../../../network-management/proxy/web-proxy.md)。
