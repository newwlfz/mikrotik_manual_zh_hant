## ip/dhcp-relay/monitor {#ipdhcp-relaymonitor}
**型別：** 命令

顯示 DHCP 中繼的計數器。

<ArgTable c1="只讀引數" c2="型別" c3="描述">
<ArgTableRow arg="requests" typ="num">中繼轉發給伺服器的用戶端請求數量。</ArgTableRow>
<ArgTableRow arg="responses" typ="num">中繼遞送給用戶端的伺服器回覆數量。</ArgTableRow>
</ArgTable>
