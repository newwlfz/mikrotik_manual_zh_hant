## ip/dns/adlist/reload {#ipdnsadlistreload}
**型別：** 命令

立即檢查所有 adlist 是否有更新，而不是等到下一次 4 小時檢查時再進行，並且只應用發生變更的部分。如果某個列表的匯入因快取過小而停止，此命令不會將其補全。
