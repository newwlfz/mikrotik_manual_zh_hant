## interface/6to4 {#interface6to4}
**型別：** 目錄

[6to4](../../virtual-private-networks/6to4.md) 是一種特殊機制，允許 IPv6 封包透過 IPv4 網路傳輸。

<ArgTable c1="標誌" c2="名稱" c3="描述">
<ArgTableRow arg="X" typ="disabled">專案是否被停用。</ArgTableRow>
<ArgTableRow arg="R" typ="running">介面是否正在執行。</ArgTableRow>
</ArgTable>

<ArgTable c1="引數" c2="型別" c3="描述">
<ArgTableRow arg="name" typ="string">介面名稱。</ArgTableRow>
<ArgTableRow arg="mtu" typ="num">Layer3 最大傳輸單元。</ArgTableRow>
<ArgTableRow arg="local-address" typ="ipAddr">封包的源地址，屬於路由器本地。</ArgTableRow>
<ArgTableRow arg="remote-address" typ="alt { address: ipAddr
, name: string
 }">6to4 隧道遠端的 IP 地址。如果未指定，則 IPv4 地址從 2002::/16 閘道器地址派生。</ArgTableRow>
<ArgTableRow arg="keepalive" typ="super { keepalive-interval: time [1 .. ]
, [keepalive-retries] [ ,num [1 .. ]]
 }">
keepalive 引數設定時間間隔，在該間隔內，即使隧道遠端發生故障，隧道的 running 標誌仍會保留。如果配置的時間間隔和重試次數失敗，則移除介面的 running 標誌。  
引數按以下格式編寫：`KeepaliveInterval,KeepaliveRetries`  
 其中 KeepaliveInterval 是時間間隔，KeepaliveRetries 是重試次數。  
預設情況下，keepalive 設定為 10 秒和 10 次重試。
</ArgTableRow>
<ArgTableRow arg="dscp" typ="num">封包的 DSCP 值。Inherited 表示 DSCP 值從待封裝的封包繼承。</ArgTableRow>
<ArgTableRow arg="clamp-tcp-mss" typ="bool">控制是否更改接收到的 TCP SYN 封包的 MSS 大小。啟用後，如果當前 MSS 大小超過隧道介面 MTU（考慮 TCP/IP 開銷），路由器會更改接收到的 TCP SYN 封包的 MSS 大小。接收到的封裝封包仍包含原始 MSS，只有在解封裝後才會更改 MSS。</ArgTableRow>
<ArgTableRow arg="dont-fragment" typ="enum (no | inherit)">
是否在相關封包中包含 DF 位。
- `no` - 如有需要則分片。
- `inherit` - 使用原始封包的 DF 標誌。
</ArgTableRow>
<ArgTableRow arg="ipsec-secret" typ="string" syscap="security">當指定金鑰時，路由器會用預共享金鑰和策略向 remote-address 新增一個動態 IPsec 對等體（預設情況下 phase2 使用 sha1/aes128cbc）。</ArgTableRow>
</ArgTable>

<ArgTable c1="只讀引數" c2="型別" c3="描述">
<ArgTableRow arg="actual-mtu" typ="num">隧道的實際最大傳輸單元。</ArgTableRow>
<ArgTableRow arg="current-remote-address" typ="ipAddr">遠端當前的 IPv4 地址。</ArgTableRow>
</ArgTable>
