## tool/traffic-generator/stop {#tooltraffic-generatorstop}
**型別：** 命令
停止由 [start](./start.md) 命令啟動的後臺流量生成器。已收集的統計資料仍可在 [stats 選單](../../../diagnostics-monitoring-and-troubleshooting/traffic-generator.md#stats)（`/tool/traffic-generator/stats/*`）下檢視。
