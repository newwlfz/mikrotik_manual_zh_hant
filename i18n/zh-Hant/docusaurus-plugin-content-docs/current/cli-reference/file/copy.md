## file/copy {#filecopy}
**型別:** 命令

複製檔案或目錄。目錄會遞迴複製，包括其所有內容。請參閱 [檔案](../../system-information-and-utilities/files.md#copy-a-file-or-directory) 指南。

<ArgTable c1="引數" c2="型別" c3="描述">
<ArgTableRow arg="name" typ="file">副本的目標名稱。可以包含路徑，以便複製到其他目錄。</ArgTableRow>
</ArgTable>
