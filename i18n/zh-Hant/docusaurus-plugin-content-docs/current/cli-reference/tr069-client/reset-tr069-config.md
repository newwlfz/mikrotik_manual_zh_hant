## tr069-client/reset-tr069-config {#tr069-clientreset-tr069-config}
**包：** tr069-client
**型別：** 命令

該命令會完全重設並清除 tr069-client 的配置和狀態（不影響其他 RouterOS 配置）。當 CWMP 進入無響應或掛起狀態，需要在無需重新安裝 RouterOS 的情況下進行恢復時，請使用此命令。
