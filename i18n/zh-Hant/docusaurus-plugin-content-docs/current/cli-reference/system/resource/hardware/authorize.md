## system/resource/hardware/authorize {#systemresourcehardwareauthorize}
**條件：** !powerpc, !smips
**型別：** 命令
允許或禁止使用 USB 硬體裝置（在 `usb-settings` 中開啟授權時使用）。

<ArgTable c1="引數" c2="型別" c3="描述">
<ArgTableRow arg="allow" typ="bool">授權 USB 裝置（`yes`）或使其保持不可用（`no`）</ArgTableRow>
</ArgTable>
