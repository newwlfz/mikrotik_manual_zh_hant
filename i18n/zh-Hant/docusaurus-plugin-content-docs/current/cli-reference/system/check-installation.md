## system/check-installation {#systemcheck-installation}
**型別：** 命令

該命令透過校驗檔案的可讀性與放置是否正確，來確保 RouterOS 系統的完整性。其主要用途是確認 NAND/Flash 儲存的健康狀況與狀態。
