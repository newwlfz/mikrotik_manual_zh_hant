## cmr/upgrade/job/show-devices {#cmrupgradejobshow-devices}
**軟體包：** cmr
**型別：** Command

顯示所選任務涵蓋的裝置。計劃任務僅在任務啟動時才解析其裝置列表，因此對於尚未啟動的任務，輸出可能為空。

<ArgTable c1="標誌" c2="名稱" c3="描述">
<ArgTableRow arg="L" typ="controller">包含 CMR 伺服器本身（自用戶端）。</ArgTableRow>
</ArgTable>
