## beep {#beep}
**型別：** 命令

使內建揚聲器發出蜂鳴聲。僅支援帶有蜂鳴器的裝置。請檢視 [mikrotik.com](https://mikrotik.com) 上的裝置頁面。

<ArgTable c1="引數" c2="型別" c3="描述">
<ArgTableRow arg="frequency" typ="num">聲音訊率，單位為 Hz</ArgTableRow>
<ArgTableRow arg="length" typ="time">聲音持續時間，單位為秒</ArgTableRow>
</ArgTable>
