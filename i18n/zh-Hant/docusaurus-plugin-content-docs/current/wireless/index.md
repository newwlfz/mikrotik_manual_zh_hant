本節將介紹 802.11 無線協定的配置以及最佳使用示例。

路由器的無線能力可以極大地提升家庭或辦公網路的可用性，也能為工業場景提供解決方案。對於缺乏經驗的使用者來說，挑選合適的裝置進行配置可能是個難題。本指南旨在解釋各種引數，並給出一種思路，幫助你在種類繁多的 MikroTik 路由器中不至於迷失方向。

### 哪個章節適合我的裝置？ {#which-section-is-for-my-device}

MikroTik 無線裝置分為多個產品系列，每個系列都透過特定的 RouterOS 選單進行配置。在下面找到你的裝置，然後跳轉到對應章節：

| 產品系列 | RouterOS 選單 | 驅動程式包 |
| :-- | :-- | :-- |
| [Wi-Fi 6 / 7 (802.11 ax/be)](./wifi/index.md) | `/interface/wifi` | `wifi-qcom`, `wifi-qcom-be`, `wifi-mediatek` |
| [Wi-Fi 5 (802.11ac)](./wifi-ac/index.md) | `/interface/wifi` *或* `/interface/wireless` | `wifi-qcom-ac` *或* `wireless` |
| [802.11 a/b/g/n](./abgn/index.md) | `/interface/wireless` | `wireless` |
| [60 GHz (W60G)](./w60g/index.md) | `/interface/w60g` *或* `/interface/wifi` | `wireless` |

802.11ac 裝置是唯一可以二選一使用哪種選單的裝置 —— [Wi-Fi 5 (802.11ac)](./wifi-ac/index.md) 章節說明了如何選擇。下面的軟體包對照表更詳細地涵蓋了這一選擇。

:::tip[不確定你的裝置屬於哪個系列？]
無線標準通常會體現在型號名稱中。例如，**wAP ax** 和 **hAP ax³** 是 802.11ax（Wi-Fi 6），**hAP be lite** 是 802.11be（Wi-Fi 7），**hAP ac²** 和 **wAP ac** 是 802.11ac（Wi-Fi 5），而 Cube **60Pro** 是 60 GHz（W60G）裝置。
:::

### RouterOS 軟體包型別 {#routeros-package-type}

部分 MikroTik 裝置可以在兩種無線 NPK 軟體包（即無線驅動程式）之間進行選擇，具體取決於所需功能和裝置型別。更多細節可在各自的文件章節中找到。無論 CPU 架構如何、也無論使用哪種無線驅動程式，CAPsMAN 功能都包含在 routeros 捆綁包中，也就是說你可以在任何型號上執行 CAPsMAN。

簡而言之：

- CAPsMAN 可以執行在任何 MikroTik 裝置上。大多數情況下，你可以同時執行新版和舊版 CAPsMAN（在 AX 路由器上同時執行兩者時，無法使用內建網路卡）。
- MIPS 型別裝置沒有驅動程式可選，僅支援舊版驅動程式。
- ARM CPU 的 802.11AC 無線裝置可以選擇無線驅動程式：wireless.npk 或 wifi-qcom-ac.npk。

下面的表格可以幫助你在這種情況下做出選擇：

### 頻段 {#frequencies}

MikroTik 提供的路由器介面涵蓋 3 個頻段 —— 2.4GHz、5GHz 和 60GHz。每個頻段都有自己的優勢和適用場景。

#### 2.4GHz {#24ghz}

如今由於過度使用而被視為舊技術，但它仍是支援最廣泛的頻段。如果你有手機、筆記型電腦或其他裝置這樣的無線用戶端，它極有可能支援該頻段。甚至 IoT 裝置也常常支援 2.4GHz 頻段。由於頻率較低，2.4GHz 頻段能更好地克服障礙物，因此相比 5GHz 裝置具有更大的覆蓋範圍，但通常吞吐量（上網速度）也更小。此外，它可能會因其他 2.4GHz 無線裝置的干擾（噪聲）而受到嚴重影響，因為幾乎每個家庭接入點都支援 2.4GHz 頻段，而且它在穿牆和長距離傳輸方面表現良好；同時可選頻率也更少（3 個非重疊通道）。如果你周圍有很多近距離的鄰居（公寓、共享辦公樓），那麼 2.4GHz 頻段很可能已經飽和，效能會下降。該頻段也可用於工業鏈路。

#### 5GHz {#5ghz}

通常，新款的手機和筆記型電腦也支援 5GHz 頻段。如果你的用戶端裝置和路由器支援 802.11ac（有時簡稱為 "ac"），那麼它比 2.4GHz 頻段更快。5GHz 頻段有更多可選頻率，但覆蓋範圍通常比 2.4GHz 頻段更小。如果你有新的用戶端裝置，ac 路由器將讓你的網路受益。由於頻率範圍大，5GHz 頻段也常用於工業鏈路。

#### 60GHz {#60ghz}

目前，支援 60GHz 頻段的用戶端裝置（手機、筆記型電腦）非常少。不過，它為工業鏈路提供了前沿的解決方案。例如，如果你有兩個點需要連線，距離最遠可達 1500 米，你將獲得 1 Gbps 的雙向鏈路。例如，MikroTik 有一款產品名為 *Wireless Wire*，因為它能提供與 1Gbps 有線連線相同的速度，但你需要無遮擋的視距才能建立鏈路。

### 使用場景 {#use-case}

MikroTik 裝置上的 RouterOS 軟體提供了廣泛而連貫的配置可能性。RouterOS 軟體讓你能以多種方式使用 MikroTik 裝置，例如，如有需要，"家庭接入點"裝置可以很容易地重新配置為用戶端或組成點對點鏈路。所謂"家庭 AP"只是預設配置，你可以將其更改為任何你想要的配置。話雖如此，最好還是按照硬體的設計用途來使用它。

#### 用於手機和筆記型電腦的家庭 AP {#home-ap-for-phones-and-laptops}

在確定最適合你的方案之前，你應該回答這樣一些問題：你想連線多少個用戶端、需要覆蓋多大範圍、想獲得多高的速度。

#### 用戶端數量 {#client-count}

連線的用戶端越多，延遲越高、吞吐量越小。為達到最佳效能，我們建議每個介面連線 20-50 個用戶端；視條件不同，用戶端數量可以增加到 100 個並仍保持穩定執行。如果用戶端需要高吞吐量，或資料流量對時延敏感，建議每個接入點規劃更少的用戶端。通常，選擇更簡單的接入點但更密集地部署它們會更有益。

#### 覆蓋範圍 {#range}

無線連線的覆蓋範圍取決於許多條件，其中包括天線增益、路由器和用戶端裝置的發射功率、來自其他裝置的干擾、障礙物（牆壁、金屬物體）以及路由器的擺放位置。需要注意的一個重要因素是，所有參與的裝置都會影響可達到的距離，這意味著無論你的 AP 多麼強大和靈敏，小手機都會受限於自身的發射功率和靈敏度。如果用戶端裝置是手機，單個裝置無法覆蓋較大區域。通常只能達到幾百米，要覆蓋更大的區域就需要更多的 AP 裝置。

- **天線增益** 以 dBi 為單位衡量，它決定了波束有多窄。0 dBi（實際上不可能）的輻射方向圖呈球形，1.5 dBi - 5 dBi 幾乎向所有方向輻射，但會有一些凹陷，某些方向訊號會更強。> 9 dBi 具有明顯的定向輻射方向圖。天線增益更高的天線如果擺放得當，就能在所需方向上覆蓋更遠。
- **發射功率** 以 dBm 或 mW 為單位衡量，它決定了無線介面發出的訊號強度。移動裝置通常發射功率較低，以節省電量。舉例來說，即使手機報告接收訊號強度良好，路由器從手機接收到的訊號也可能很弱。

- 來自其他裝置的 **干擾** 會抬高噪聲底，路由器就更難從噪聲中分辨出訊號，因此訊號必須更強，用戶端必須離接入點更近。同一頻率上的接入點佔用相同的空口時間，從而降低吞吐量並增加延遲。

- 一些 **物體** 會降低（衰減）訊號強度，另一些則會反射訊號。在建築物中，通常必須考慮牆壁及其厚度、地板和天花板、金屬物體。玻璃和木材也會衰減訊號。

- 接入點的 **擺放位置** 也會影響覆蓋範圍。接入點不應被金屬物體或表面遮擋，這樣訊號才有空間傳播。

#### 速度 {#speed}

如果速度很重要，那麼你應該選擇支援 802.11 ac 的 5GHz 無線路由器。

### 用於連線其他無線天線（CPE 到 AP） {#for-other-wireless-antennas-to-connect-cpe-to-ap}

通常需要連線兩個或多個點，例如連線園區內的建築、將用戶端家庭接入網路，或建立長距離鏈路。MikroTik 在這些場景下同樣提供瞭解決方案。為了做出選擇，你必須瞭解距離、需要連線的是兩個點（點對點 - PtP）還是多個點（點對多點 - PtMP），以及你需要什麼速度。

#### 距離 {#distance}

由於在這些場景中我們面對的是定向天線和遠距離，你必須牢記對準和無遮擋視距至關重要。對於最遠 1500 米的小距離，我們建議使用 60 GHz 裝置，它能提供穩定性和出色的速度。此外，在短距離下，天線增益較小的 2.4 GHz 或 5 GHz 裝置也完全夠用，儘管你無法獲得 60 GHz 裝置那樣的速度。對於更長的鏈路，則應考慮天線增益和發射功率。更高的訊號強度可實現更高的資料速率，也就意味著更高的吞吐量。明智地選擇頻率，以避免與其他無線鏈路產生干擾。請記住，在城市中即便在屋頂之上，也常常存在來自鄰近 2.4 GHz 和 5 GHz 鏈路的干擾。

#### PtP 還是 PtMP {#ptp-or-ptmp}

PtP 和 PtMP 鏈路在某些方面有所不同。對於 PtMP，你可能需要一個波束更寬的天線，也就是所謂扇形天線。這種天線覆蓋角度更寬，但增益更低，因此距離更短。此外，在 PtMP 中，接入點必須至少具有 4 級 RouterOS 軟體許可。連線到接入點的用戶端或裝置以及 PtP 鏈路中的裝置可以具有 3 級許可和更窄的波束寬度。

#### 速度 {#speed-1}

對於短鏈路中的更高速度，你必須選擇 60 GHz 裝置；對於更長的距離，則選擇 5GHz ac 裝置。

#### 注意 {#note}

要控制大型接入點網路，你可以使用 CAPsMAN —— 一個能從單一位置為眾多接入點進行配置的控制器。請使用與你的裝置選單相匹配的控制器：對於 `/interface/wifi` 裝置（`wifi-qcom` / `wifi-qcom-ac`），使用 [WiFi CAPsMAN](./wifi/capsman.md)；對於舊版 `/interface/wireless` 裝置，使用 [CAPsMAN](./abgn/capsman/index.md)。要控制數百個接入點，我們建議使用我們的 CCR 系列裝置。要控制數千個接入點，你或許可以嘗試使用 CHR 或 x86 機器。
