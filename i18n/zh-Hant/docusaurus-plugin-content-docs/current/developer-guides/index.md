本節介紹 RouterOS 的自動化與整合介面——API、指令碼以及 REST API。當你要構建與 RouterOS 互動的工具、指令碼或應用程式時，請使用本節內容。API 和 REST API 允許外部工具透過網路與路由器通訊；指令碼則執行在路由器本身上。
